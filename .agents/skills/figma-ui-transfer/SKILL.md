# Редактируемый мастер и перенос
Адаптация [Dune GoH #320](https://github.com/mryandexxx-spec/Dgoh-game/pull/320) и подтверждённого офлайн-эксперимента [#325](https://github.com/mryandexxx-spec/Dgoh-game/pull/325). Основано на [официальной документации Figma](https://developers.figma.com/docs/figma-mcp-server/). При использовании Figma загружать установленные обязательные figma-create-new-file, figma-use, figma-generate-design, figma-design-to-code или figma-generate-library по назначению. Этот skill их не заменяет.

- Исходные ассеты и семантические слои отдельно. Landscape 844×390, 932×430, 844×320, дополнительный 667×375; живые подписи и отдельные состояния. Общие переменные/компоненты; безопасные зоны, касание 44px+, фокус/возврат, отсутствие скролла корня. Шрифты и палитра проекта из фактической UI-системы.
- Если Figma блокирует доступ, не повторять бессмысленные вызовы. Создать локальный редактируемый SVG-мастер с именованными слоями, отдельными ассетами, manifest и исходным генератором, не полный растр. Inkscape для независимого экспорта/проверки; подтвердить доступность инструментов перед обещанием. SVG — дизайн, не функциональное доказательство. Записать фактическое ограничение Figma.
- При переносе использовать ванильный DOM/CSS, существующие механики и ассеты; не добавлять React/Tailwind, не заменять 3D кампании плоским фоном, не переписывать правила/сейвы. Сопоставлять эталон и реальные скриншоты в одинаковых состояниях. Сначала изолированная лаборатория, production только после художественной/функциональной приёмки.
