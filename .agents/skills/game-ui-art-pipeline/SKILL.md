# Производственный конвейер игрового UI
[ПРЕДЛОЖЕНИЕ — методика, не новый канон]. Адаптация собственной методики Dune GoH GFX-06/PIPELINE-01, [PR #320](https://github.com/mryandexxx-spec/Dgoh-game/pull/320), исходная версия 3f721bc7. Вдохновлена [Layer Game UI](https://github.com/layerai/skills/blob/main/plugins/layer/skills/layer-game-ui/SKILL.md) и [Figma MCP](https://developers.figma.com/docs/figma-mcp-server/). Не утверждать, что внешние плагины установлены или оплачены.

1. Прочитать game-ui-ux, create-game-assets, UI_DESIGN_SYSTEM.md, UI_MIGRATION_PLAN.md, актуальные документы задачи и канон мира по необходимости. Восстановить точный принятый референс (байты, SHA-256, происхождение, решение владельца). Если его нет — новый кандидат, не подменять согласованный эталон. SWGOH — ориентир читаемости и удобства, не источник копируемого искусства.
2. Отдельно проектировать композицию, свет, материалы, иерархию и действия. Для карточки героя — центральный персонаж, единое пространство, читаемые обычное развитие, личная арка и специализация; не панель из одинаковых карточек. Сначала художественная композиция, затем функциональный макет; не доводить слабую основу десятками CSS-итераций.
3. Производить независимые слои: фон без интерфейса/надписей, при необходимости архитектура, свет, контактная тень, персонаж/портрет, панели/рамки, пиктограммы, живой текст и состояния. Прежде всего переиспользовать существующие принятые игровые портреты и иконки. ImageGen — для явно необходимого художественного компонента при запросе на изображение, не заменяет редактируемый макет; отклонять целый растр UI, неверные предметы и чужую стилистику. Никаких автоматических платных fal/Figma вызовов, покупок или повторов. При лимитах применять Pillow, SVG, Inkscape и ручные маски. Оригиналы не уничтожать.
4. Ограниченный набор общих UI-скинов (primary, selected, normal, panel edge, divider), при необходимости nine-slice/border-image с проверкой на крайних размерах; не запекать текст в фон. Хранить manifest: исходник/лицензия, формат, размеры, alpha, slice insets, байты, назначение и SHA-256. Не добавлять runtime-зависимости или постоянно работающие эффекты.
5. Собрать редактируемый мастер по figma-ui-transfer, сравнить состояния в actual Chromium/WebKit по game-ui-visual-review. Арт и технику принимать раздельно. Не выдавать прототип за игру.
