# Пепельный престол — браузерный прототип

Мобильная браузерная коллекционная пошаговая RPG на Babylon.js. Рассчитана на смартфоны в горизонтальной ориентации, в первую очередь iPhone Safari. Сейчас это рабочий прототип вертикального среза, а не законченная игра: большинство героев, миссий и чисел демонстрационные.

- **Играть:** https://mryandexxx-spec.github.io/ashes-throne-prototype/ (номер сборки в футере)
- **Текущее состояние:** [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md)
- **История изменений:** [docs/CHANGELOG.md](docs/CHANGELOG.md)
- **Дизайн игры:** [docs/Pepelny_tron_GDD_3.0.md](docs/Pepelny_tron_GDD_3.0.md), бой — [docs/Combat_Specification_1.0.md](docs/Combat_Specification_1.0.md)
- **Правила работы для AI и разработчиков:** [docs/AI_WORKFLOW.md](docs/AI_WORKFLOW.md)

## Что есть в прототипе

Штаб, коллекция и карточка героя с экипировкой, умениями и звёздами; кампания, испытания, разведывательные операции, задания дня, календарь входа, профиль игрока; ручной пошаговый бой по инициативе с добровольным автобоем на 3D-арене. Рен и Нада представлены анимированными GLB-моделями. Подробный перечень и уровни проверки — в [PROJECT_STATUS](docs/PROJECT_STATUS.md).

## Запуск локально

Сборка не нужна. Нужен любой статический веб-сервер из корня репозитория, например:

```bash
npx serve .
# или
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000/` (или адрес, который выведет сервер). Открывать `index.html` двойным щелчком нельзя: Service Worker и загрузка GLB работают только по HTTP.

Babylon.js 9.33.2 и шрифты загружаются с CDN. Без доступа к ним 3D-арена и карточки героев не отрисуются.

## Тесты

```bash
npm test
```

Команда проверяет синтаксис модулей (`node --check`) и запускает Node-тесты из `tests/` (`node --test`). Нужен Node 22. Браузерные проверки в Chromium и WebKit запускаются в GitHub Actions (`.github/workflows/`).

## Структура

| Путь | Назначение |
|---|---|
| `index.html`, `styles.css`, `hero-card.css` | Разметка всех экранов и стили; скрипты подключаются по порядку в `index.html` |
| `game.js` | Интерфейс, навигация по экранам, связка логики с 3D |
| `*-core.js`, `*-data.js` | Логика и данные без DOM: бой, инициатива, умения, прогресс, сохранение, режимы |
| `arena-*.js`, `combat-*.js`, `battle-*.js` | Арена, камера и формация, World HUD, окружение, анимации боя |
| `ren-*.js`, `nada-glb-runtime.js` | Загрузка и анимация 3D-моделей героев |
| `model-cache-sw.js`, `model-cache-client.js` | Service Worker: постоянный кеш двух GLB |
| `assets/` | Изображения интерфейса и модель Рена |
| `dev/assets-src/`, `dev/assets/models/`, `dev/src/assets/` | Исходники ассетов, игровые GLB, реестр моделей |
| `tools/` | Служебные скрипты, например `optimize-hero-glb.mjs` |
| `tests/` | Node-тесты и браузерные сценарии |
| `docs/` | GDD, спецификации этапов, статус, changelog; `docs/archive/` — прежние журналы |
| `design/` | Макеты и материалы визуального дизайна |
| `ren-*.html` | Отдельные служебные стенды для проверки модели Рена |
