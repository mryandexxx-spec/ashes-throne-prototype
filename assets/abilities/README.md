# Иконки способностей (ARENA-UI-003)

Круглые кнопки способностей в бою берут картинку отсюда. Пока файла нет, на кнопке временная пиктограмма по типу способности.

**Имя файла:** `<герой>-<слот>.webp`, где слот — `basic`, `special` или `powerful`.
Примеры: `ren-basic.webp`, `nada-special.webp`, `liora-powerful.webp`.

**Формат:** квадрат, WebP, 256×256 (достаточно для кнопки 60–76 px при DPR 3), до ~25 КБ. Главный предмет в центральных ~70%: край обрезается кругом. Промпты — `docs/ABILITY_ICON_PROMPTS_001.md`.

**Подключение:** добавить имя файла в `manifest.json`, например `{"icons": ["ren-basic.webp", "ren-special.webp"]}`. Игра читает список один раз за сессию и не запрашивает файлы, которых в нём нет, поэтому на iPhone нет лишних запросов и ошибок 404.
