# Пиктограммы материалов снаряжения

Каждый файл — отдельное изображение WebP 160 × 160 с прозрачностью. Чтобы заменить рисунок, сохраните новый WebP под тем же именем и регистром. Рецепты и экранные ссылки используют постоянный идентификатор. Для обновления кэшированных картинок при релизе смените версию изображений в функции `icon` в `gear-material-ui.js`. Количества, рамки и отметки достаточности рисует интерфейс.

| Файл | Материал | Что различимо при малом размере |
|---|---|---|
| Fe.webp | Железо | Два тяжёлых кованых бруска |
| Le.webp | Кожа | Завёрнутый край, замшевая изнанка и отверстия от шва |
| Cl.webp | Ткань | Светлое сложенное полотно с бахромой |
| Wo.webp | Древесина | Торцы двух колотых заготовок |
| Fa.webp | Крепёж | Изогнутая скоба рядом с двумя гвоздями |
| Th.webp | Прочная нить | Витки тонкой нити на плоском мотовильце |
| Gl.webp | Стекло | Две плоские полупрозрачные пластинки |

Для художественной сверки использованы WORLD_STATUS, CURRENT Садов над пропастью и утверждённая редакция 1.5 «Пяти теней». В тексте встречаются железные скобы настила, дощечки, кожа переплёта, нить у корешка, ткань и оконное стекло. Из рабочей модели региона CURRENT_RESEARCH_1.1 взят мотив повседневного обслуживания и ремонта. Цвет и форма отдельных образцов — художественная интерпретация [ПРЕДЛОЖЕНИЕ]. Описания применения в интерфейсе сверены с рецептами игры.

Иллюстрация сгенерирована для проекта в ImageGen единой таблицей 4 × 2, затем разделена на семь самостоятельных изображений. Задание для воспроизведения: изолированные образцы ремесленного сырья, крупный читаемый силуэт, тёплый свет сверху слева, прозрачный фон, без рун, надписей и декоративных рамок. Порядок и предметы перечислены в таблице.
