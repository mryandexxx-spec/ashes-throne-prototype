# RESICON001 — опыт аккаунта и материалы способностей
[УТВЕРЖДЕНО] Визуальные образы одобрены владельцем 22.11.2026.
[РЕАЛИЗАЦИЯ] Единый WebP-атлас 2×2 (иконки: account-xp, manual1, manual2, seal), прозрачный фон, читаемость при 32–48 CSS px. Рамки, цифры и состояния рисует интерфейс.
Порядок ячеек: слева сверху — Account XP (золотой знак), справа сверху — Учебник I, слева снизу — Учебник II, справа снизу — Печать мастерства.
Атлас: assets/resources/atlas.webp. Размер при добавлении: около 6–12 КБ. Единая точка отображения: resource-icon-ui.js / resource-icon-ui.css. Чтобы заменить один рисунок, укажите путь к его WebP через ResourceIconUI.OVERRIDES.manual1 (и т. д.) либо замените атлас и увеличьте ?v= в CSS.
Иконка является интерфейсной иллюстрацией, не каноническим предметом мира; новых игровых валют/материалов не создано. Account XP относится только к уровню аккаунта. Подтверждённые источники в карточке собираются из DailyCore / LoginCore, а переход к кампании ведёт на её основной экран.
Тап по иконке открывает диалог; поддержаны Esc, закрытие по нажатию на фон, возврат фокуса. Нажатие на источник ведёт на экран активности. После применения навыка реальные списания и выплаты остались в существующих ядрах.

## KROM001 — утверждённый Кром (22.11.2026)
**[УТВЕРЖДЕНО]** Название основной игровой валюты «Кром» и художественный образ монеты с буквой «К» и срезанным краем. Это игровое обозначение; никакой единой валюты всего мира либо государственного чеканного двора не канонизировано.
Файл `assets/resources/krom.webp`: 96×96, RGBA WebP, 4700 байт (проверено декодирование; исправление KROM002); отдельная прозрачная картинка, не объединённая с атласом XP/учебников. CSS-класс `.resource-art--krom` в `resource-icon-ui.css`; для замены достаточно подменить файл (после этого изменить `?v=`), либо задать `ResourceIconUI.OVERRIDES.krom` для другого WebP.
Идентификатор внутри механик и сохранений остаётся `progress.currency`. Карточки интерфейса отображают Кром и источники из существующих каталогов. Экономический баланс и механика выплат не менялись.
