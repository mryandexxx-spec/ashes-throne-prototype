# ARENA-UI-003 — HUD боя по схеме SWGOH

**Дата:** 20.11.2026. **Основание:** [аудит арены](COMBAT_ARENA_AUDIT_001.md), раздел 2 (таблица D) и раздел 4. Предыдущие этапы: [ARENA-VIS-001](ARENA_VIS_001.md), [ARENA-VIS-002](ARENA_VIS_002.md).
**Разбиение:** два PR по зонам экрана, чтобы каждая сборка была законченной.
- **ARENA-UI-003A** (`v0.3.205 · ARENAUI003A`): каркас HUD — очередь ходов, активный герой, круглые способности, удаление служебных элементов.
- **ARENA-UI-003B**: таблички над бойцами (жёсткая привязка, имена только у активного и цели, числа VIS-002 без перекрытий).

**Решения владельца 20.11.2026:** временные пиктограммы способностей по типу — **[УТВЕРЖДЕНО]** до появления сгенерированных иконок. Лента очереди — сверху, с кнопкой сворачивания — **[УТВЕРЖДЕНО]**. Размеры, цвета и раскладка остаются **[ПРЕДЛОЖЕНИЕМ]** до приёмки на iPhone.

## ARENA-UI-003A — каркас HUD

| Зона | Было | Стало |
|---|---|---|
| Верх слева | «✕ В меню», «Автобой», «1×», «Ход N», текстовая плашка «Журнал боя · N событий» | Две кнопки 44×44: «✕» и журнал (иконка). Журнал открывается списком под кнопкой |
| Верх по центру | «ТЕСТОВАЯ АРЕНА / Ход: …», служебное «Действие выполняется…» | **Лента очереди ходов**: тот, чей ход (крупнее, золотое кольцо), и 5 следующих. Союзники в голубом кольце, враги в красном. Справа «Волна N/M» (если волн несколько) и кнопка сворачивания. Свёрнутая лента показывает только текущего бойца; выбор запоминается между боями. Под лентой одна строка цели боя, по касанию раскрывается |
| Верх справа | Карточка «ЦЕЛЬ: ПРОТИВНИК» | Свободно: там шеренга врагов. Цель обозначают прицел и красное кольцо |
| Низ слева | Строка статуса «Отряд готов к бою» | Портрет и имя того, кто ходит; рядом «Автобой» и «1×» |
| Низ справа | Карточка «ДЕЙСТВИЕ» с заголовком, подсказкой и тремя широкими текстовыми кнопками | Три круглые кнопки 60 px (мощная 66 px). Перезарядка — числом поверх затемнённой иконки. Название и описание — по долгому нажатию. Подсказка над кнопками появляется, только если следующий шаг не «коснись врага»: выбор союзника, автобой, выбор цели |

**Очередь ходов** — прогноз: то же правило `InitiativeModel` (порог 1000, ничья по порядку) на копии шкал с `CombatCore.effectiveStat`. Бой не изменяется. Эффекты, которые враги наложат по ходу, прогноз не предугадывает; после каждого действия лента пересчитывается. Node-тест сверяет прогноз с реальным порядком `CombatCore` в живом бою.

**Иконки способностей.** Пока файлов нет, на кнопке пиктограмма по данным способности: удар, пролом (ослабление и метки), мощный удар, удар по всем, щит, лечение, страховка, сигнал, согласованный шаг. Цвет кольца по типу из `ABILITY_ICON_PROMPTS_001`. Готовые иконки кладутся в `assets/abilities/<герой>-<слот>.webp` и вписываются в `assets/abilities/manifest.json` (см. README там же). Игра читает список один раз за сессию и не запрашивает файлы, которых в нём нет: на iPhone нет лишних запросов и 404.

**Состояния кнопки** (`data-state`): `ready` — можно нажать; `wait` — ещё идёт анимация прошлого действия (чуть приглушена); `cooldown` и `locked` — затемнена; `auto` — ходом управляет автобой. Правила `disabled` прежние (Combat-009/012B).

**Доступность.** Строки статуса и сообщений боя остались для экранного диктора (`.sr-only`, `role="status"`). У кнопок `aria-label` с названием и перезарядкой, у ленты — перечисление очереди, у кнопки сворачивания — `aria-expanded`. Все касаемые элементы не меньше 44×44, у кнопки ленты расширенная зона касания. `prefers-reduced-motion` отключает переходы.

**Попутно исправлено.** На коротком landscape (высота ≤ 540 px) старое правило `.action-panel p{display:none}` скрывало описание способности в подсказке долгого нажатия. Теперь описание видно.

**Не менялось:** `CombatCore`, правила, порядок ходов, способности, автобой, сохранения, экономика, 3D-сцена, камера, таблички над бойцами (это 003B).

### Нагрузка на iPhone
- Новых render loop, таймеров и слушателей кадра нет. Лента и кнопки перестраиваются только при изменении (сравнение подписи), а не на каждом `syncBattleUI`.
- Без `backdrop-filter`, размытия и бесконечных анимаций. Портреты — уже загруженные `*-portrait-ui.webp` (5–16 КБ).
- Один запрос `manifest.json` за сессию.

### Чек-лист на iPhone
1. Футер вне боя: `v0.3.205 · ARENAUI003A`.
2. Вверху по центру лента ходов; первым — тот, чьё золотое кольцо на сцене. Кнопка «‹» сворачивает и разворачивает ленту, выбор сохраняется в следующем бою.
3. Внизу слева портрет и имя героя, «Автобой», «1×» нажимаются.
4. Круглые кнопки нажимаются пальцем. После особой способности на ней число перезарядки, кнопка затемнена. Долгое нажатие показывает название и описание.
5. Сава или Арт: после нажатия особой способности над кнопками подсказка выбрать союзника.
6. Журнал открывается кнопкой-иконкой и закрывается повторным касанием.
7. Повтор боя и выход в меню работают; на экране нет «Тестовой арены», «Хода N», «3D … загружена», карточки цели и «Действие выполняется…».

### Риски
- Таблички над бойцами ещё раскладывает старый упаковщик, числа VIS-002 могут их перекрывать. Это 003B.
- Пиктограммы временные; финальный вид — иконки владельца.
- У Каэля, Лиры, Дарина и NPC нет портретов: в ленте инициалы.
