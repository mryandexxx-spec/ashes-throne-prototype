# ART-SAVA-PORTRAIT-001 — портреты и временные 3D-заглушки вместо моделирования

**Дата:** 2026-11-15. **[УТВЕРЖДЕНО]** отказаться от индивидуального 3D-моделирования Арта и Савы на текущем этапе. Использовать утверждённые A-позы для портретов; в бою — существующие недорогие Babylon-модели-заглушки. **Не путать решение о графике с утверждением боевого набора или регистрацией героев.**

## Что уже есть в игре

- `game.js`: базовая сцена создаёт для бойцов `BABYLON.MeshBuilder.CreateCapsule` (тело), `CreateSphere` (голова), `CreateCylinder` (основание), кроме специализированного `RenVisualModel`; индивидуальные GLB Рена, Нады и Лиоры подключаются отдельно и только по соответствующему ID. Для Арта и Савы можно повторно использовать **имеющуюся** геометрию без тяжёлых ассетов.
- `index.html` / `game.js`: карточка героя и ростер поддерживают изображения `assets/*-portrait-ui.webp` и `assets/*-portrait-roster.webp` для уже добавленных героев. Для будущих Арта и Савы потребуется отдельное компактное расширение привязки идентификаторов к WebP.
- Игровые постоянные схемы `HeroCollectionCore`, `StarCore`, `SkillCore`, `ProgressV3Core` **пока не содержат** `art` и `sava`; добавлять их по отдельному безопасному кодовому PR после решения по базовым игровым действиям. Не делать их обладателями оружия или уникальных атак автоматически.

## Приоритет реализации

1. Загрузить два **оригинальных** PNG в приватный репозиторий по путям из `ART_SAVA_A_POSE_ASSETS_1.0_2026-11-15.md` (PR #67) и четыре WebP в `assets/` игры (PR #331 или отдельный PR визуального этапа). Сверить SHA-256.
2. Отдельным кодовым PR подключить портреты к карточке/ростеру, а штатную базовую Babylon-геометрию к героям. Не пытаться загрузить несуществующие GLB и не допускать ошибок в `RenCard3D.activate`.
3. Если Арт и Сава станут постоянными выбираемыми союзниками: согласовать минимальный **пилот игрового действия**, расширить валидаторы и безопасную v3-миграцию с отдельным backup `before-art-sava`; не трогать сохранённый состав отряда, флаги сюжетной кампании и уже оплаченные ресурсы.
4. Проверить нормальный бой и автобой, смерть/победу/поражение/повтор, биографии, выбор команды, сохранения старого игрока, iPhone Safari landscape, запас GPU памяти, версию футера/код сборки.
