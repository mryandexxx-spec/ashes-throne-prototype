## Реализация
- HTML/CSS, model.js (controller) и ui.js (DOM), без новых зависимостей; source of truth AbilityData/SkillCore, CombatCore, CombatStatusCore, AutoDecision. HeroStatsCombatBridge и настоящий G pipeline в памяти. 5 presets: Ren/Art, Ren/Art/Nada, full five, waves, Sava/Ren; 3 tiers G1/G7/G13, seed, normal/hard. NPC используют реальные archetypes и исследовательские HP/ATK pressure factors, не фактические миссии. Все боевые вызовы native; никаких runtime string patches, eval или манипуляций полями бойцов в UI.
- Layout: dark graphite, bronze/gold, real portraits and existing AbilityIconCore atlas; NPC image uses its basic ability atlas as a visual marker (not an NPC portrait). Active fighter, target borders, HP/Protection/meter bars, current order forecast, threat/taunt, guards/marks/slow/disrupt/boost, cooldowns. Six projected turns assume no new effects; do not claim guaranteed order. Short selected-unit feedback and full details under ?; journal with root/assist events, wave/restart, named actor snapshots. Use DOM textContent, no global scrolling; safe-area, landscape primary, portrait fallback.
- Enemy choice then direct damaging skill; self/group buttons execute directly. Ally-target skills and joint P enter explicit selection mode, helper is not auto-selected. Tap target/helper, preview and confirm or cancel. Panel replaces footer instead of blocking battlefield. Same executor, no turn consumption during selection or cancel. Signal forecast actual gain and crossing nearest enemy, zero gain disabled. Invalid actions stop auto and report error. Auto step/run/stop; timer cancelled on hidden tab/terminal/restart/dialog.
- No changes to base combat numbers, live ability definitions, game.js/index.html, production 3D/HUD, rewards or save. No version bump for independent lab. Existing ability art is reused; artistic acceptability of new semantics not claimed.
