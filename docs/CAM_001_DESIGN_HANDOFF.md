## Предварительный игровой контракт (не сценарий)
Линейная основная глава из шести боевых миссий (первоначальные семь слотов сокращены после критики, пролог отдельно). Короткое сюжетное обоснование, выбор доступного отряда, бой, реальный результат, награда, следующее действие. Плановые ID CAM-01-01…06, не финальные ключи.
| Слот | Игровая задача | Результат |
|---|---|---|
| 01 | Первый реальный бой из main campaign, 2 различимых противника | Свободный старт и первая победа |
| 02 | Быстрый противник/дальний урон; выбор цели | Цель героя/первое знакомство с получением |
| 03 | Защита + лечение врага; приоритеты | Доступное улучшение экипировки |
| 04 | Поддержка/контроль, новая комбинация состава | Понимание роли синергии |
| 05 | Две волны в рамках проверенного боевого контракта | Выносливость, подготовка, расширение состава при принятии |
| 06 | Финальное сочетание освоенных тактик | Конечная цель главы, ясный следующий маршрут |
Кандидаты NPC: npc-pass-guard, npc-trail-interceptor, npc-ridge-slinger, npc-field-medic, npc-route-signaller, npc-watch-captain (npc-enemy-data.js). Не добавлять боевые правила или считать их биографии каноном. Фактические умения сверить с ability-data.js. Целевой темп 2–4 минуты бой (ранние короче), 15–30 минут глава; не измерено. Не заставлять фармить/ждать таймер. Первое прохождение бесплатно по GDD, повтор по существующей политике. Звёзды отдельно от прогресса, пороги только после симуляции. Не менять числа наград. Сеть показать по мере полезности и направить на существующую доступную зацепку после главы; не блокировать/изменять её доступ, таймеры, экономику, влияние без отдельного решения. Не принуждать проходить хронику.
