## Аудит и первый кандидат

ProgressV3Core.fresh уже использует START, validateActive сверяет зеркало unlockedHeroes с rank. Нулевой ранг запрещает вход в обычный отряд и покупку героя осколками; осколки сохраняются для будущего повышения. RewardPolicyCore поддерживает first-clear heroGrants с occurrence once, доказательством и существующим writer lock; ранг, зеркало, receipt и обычные награды одной записью. Нет действующего источника heroGrants; тестовая конфигурация только в тестах. Существующий M1 без grant. Закрытые карточки больше не разыменовывают null; источник без фиктивного номера миссии. Обязательные герои хроники временно участвуют без изменения владения; guest базовый 1★/1 ур. без экипировки, временный состав. Это технический кандидат, не изменение канона.
