# Challenges-001A — самостоятельное ядро испытаний

**Дата:** 2026-11-08. **Статус:** [В РАЗРАБОТКЕ] технический этап, PR на согласование. Не является реализацией пользовательского режима.

## Одобренные владельцем принципы
- Обычные испытания получают 1–3★; победа на 1★ открывает следующую ступень соответствующего направления.
- Порядок уничтожения целей строгий: гибель нескольких противников в результате одной логической способности не засчитывается как уничтожение приоритетной цели первой.
- «Натиск» — последовательные волны в одном бою, без замены состава и с сохранением состояния союзников.
- Повторы обычных испытаний свободные. Экономика, энергия, награды, осколки не проектируются.

## Реализуемый объём в этой ветке

Новый самостоятельный `challenge-core.js` реализует технические правила двух учебных ID:
- `T-01` «Первая цель»: два существующих тестовых противника, приоритет — `ves`. 1★ победа, 2★ единственный первый погибший враг `ves`, 3★ также без погибших союзников.
- `N-01` «Два рубежа»: волна `ves` и `shade`, затем `ves-2`. 1★ победа после второй волны; 2★ также все союзники выжили. **Порог действий для 3★ не утверждён**; хранится `null`, третью звезду этот технический этап не выдаёт.

Трекер собирает смерти по логическим событиям `ability`, а не по анимациям. Следующая способность создаёт следующую группу; пассивные события внутри одного действия остаются в прежней группе. Применение трекера к фактическому интерфейсу ещё не реализовано.

Прогресс `bestStars` хранится под **отдельным ключом** `ashes-throne.challenges.v1`, версия схемы — 1. Разрешено сохранять только известные ID и оценки 0..3. Повреждённые записи блокируют перезапись. Модель результата чистая: сначала вычисляется кандидат, затем он должен быть сохранён, и лишь после успеха может стать видимым постоянным прогрессом.

## Чего здесь НЕТ

- Нет кнопок и пользовательского экрана испытаний, нет переключения обычного боя на вызов `ChallengeCore`.
- Нет изменения `game.js`, `index.html`, боевого ядра, условий и сохранения кампании.
- Нет повышений версий, так как **публикуемая игра фактически не изменяется**.
- Нет утверждённого баланса на стартовом составе. В числе прочего, нельзя обещать, что 3★ N-01 доступны до согласования лимита.

## Проверки

Доступный рабочий сценарий — `npm test` через GitHub Actions.
