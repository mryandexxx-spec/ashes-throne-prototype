# CHAL002 — разделение режимов испытаний, тестовые миссии и ежедневные задания

**Статус:** [В РАЗРАБОТКЕ], PR #145. Заявленная игровая сборка `v0.3.68 · CHAL002`. Владелец попросил не настраивать боевой баланс.

## Изменения UI
Раздел «Испытания» открывает две большие кнопки: «Тактические задачи» и «Натиск». Внутри показываются отдельные списки миссий и кнопка возврата к выбору режима. Две ветки прогресса не смешиваются; победа на 1★ открывает следующую миссию **своего** режима.

Добавлено по три новые **тестовые** миссии в каждом направлении:
- T-01 «Первая цель» (без изменений), T-02 «Быстрая угроза», T-03 «Выделенная цель», T-04 «Смена приоритета». Для каждого сценария — конкретная первая цель из существующих шаблонов противников.
- N-01 «Два рубежа» (без изменений), N-02 «Смена караула», N-03 «Три рубежа», N-04 «Длинный натиск». Две или три волны из **существующих** врагов; HP/способности/скорость/урон не изменялись.

Звёзды T — 1★ за победу, 2★ за строгое первое устранение отмеченной цели, 3★ плюс без потерь. Звёзды N — 1★ за все волны, 2★ плюс без потерь; **лимит действий для 3★ не утверждён, поэтому 3★ пока недоступна**.

## Ежедневные задания
Два дополнительных задания:
- «Участвовать в тактической задаче»
- «Участвовать в Натиске»

Достаточно завершить сражение: победа **или поражение**, включая авто. Вход и выход до завершения не засчитываются. Отдельные отметки на каждую активность, максимум 1 в день.

В обоих заданиях применяются **временные тестовые** пакеты, сопоставимые с существующими ежедневками: 200 валюты, 15 XP и 2 существующих материала; это не утверждённый баланс экономики.

Кнопка «Забрать всё» получает **только уже выполненные и ещё не полученные** ежедневные награды. Все они готовятся как одна транзакция и записываются **одним** вызовом сохранения `progress.v3`. При ошибке сохранения полный снимок состояния восстанавливается, повторное начисление невозможно.
