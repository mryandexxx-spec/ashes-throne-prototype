# CHAR-002 — индивидуальные способности Рена и Нады (техническая итерация)

**Статус:** [В РАЗРАБОТКЕ]. **Числа — [ПРЕДЛОЖЕНИЕ], не утверждённый баланс.**  
**Основание:** направление CHAR-001 (PR #293; отдельный дизайн PR остаётся открытым), игровая GDD 3.0, актуальный CombatCore.

## Границы
- Только постоянные игровые герои `ren` и `nada`; сюжетные `trial-*` и манекены не меняются.
- Без новых 3D-моделей, анимаций, оружейного канона, лидерских способностей, серверов и новых ресурсов.
- Существующая прокачка активных умений L1–L6 и стоимость материалов остаются тестовыми; пассивные способности пока **только L1**. Отдельной прокачки пассивов нет и она не показывается в UI.

Рен: пассивное «Чувство тропы» — +15% собственного урона по врагам с негативным эффектом. Существующие пробные бонусы по тегу происхождения и шансам статусов не менялись этим PR и требуют отдельного решения по финальному набору.

Нада: пассивное «Внимание к деталям» — пока она жива, всем союзникам, включая саму Наду, +10% урона по врагу с негативным эффектом. Бонус **складывается** с пассивным бонусом Рена, не перемножается. Две копии одного ID в бою не суммируются (в текущем ядре действует защита от одинаковых ID).

«Прицельный выстрел» — рабочее название уже существующего игрового действия. Не утверждает в каноне конкретное оружие Нады.

## Техническая реализация
- `ability-data.js`: стартовые параметры и активный пассив Нады.
- `skill-core.js`: две изолированные таблицы развития активных умений L1–L6 (исключение из демоформулы).
- `combat-core.js`: общий декларативный бонус союзникам по врагу с негативным эффектом, не привязанный к имени героя.
- `ability-info.js`: описание реальных механик пассива и одиночного ослабления сопротивления.
- `tests/char-002-abilities.test.js`: полная таблица L1–L6, отсутствие изменения `trial-*`, проверка урона 32 → 35, область действия мощных способностей и перезарядок.

## Не завершено
1. Художественное согласование названий и оружия Нады.
2. Подтверждение баланса и общей экономики улучшений.
3. Развитие пассивных способностей (отдельная система и интерфейс, если согласовано).
4. Смоук-тест на физическом iPhone Safari и приёмка владельца.

Отсутствие этих пунктов нельзя скрывать словом «готово». Слияние PR только после отдельной команды владельца.
