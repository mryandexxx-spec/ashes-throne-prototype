# CHAR-002 — Рен / Нада: индивидуальная система способностей

**Обновлено:** 2026-11-13. **Статус: [В РАЗРАБОТКЕ], цифры [ПРЕДЛОЖЕНИЕ], код в Draft PR #300, не в main.**

## Решение владельца и отличие от прежнего набора

Владелец отверг прежний дизайн, где Рен усиливался от любого отрицательного эффекта, а Нада использовала обычный дебафф и пассивный бонус урона всей группе. Новое требование: уникальные **складывающиеся зацепки Нады**, удар Рена тем сильнее, чем больше этих зацепок на враге, оба героя с тегом Садов и собственными региональными пассивами.

Источник детального игрового и лорного решения: [CHAR-002B «Просчитанный ход»](CHAR_002B_READ_MOVE_DESIGN_PROPOSAL.md). Художественное объяснение **не является утверждённым каноном**.

## Механика, присутствующая в ветке PR #300

- Статус **«Просчитанный ход»** (`read-move`): до четырёх зацепок, наложение складывается, длительность 2 собственных хода цели; повторное наложение обновляет срок. При попытке противника применить особую/мощную способность с 3+ зацепками она заменяется базовой, тратятся 3 зацепки. Враги не теряют ход; срыв показывается в журнале.
- **Рен:** пассив «Чувство тропы» даёт +12% урона лично Рену за каждую **зацепку**, а не за другие негативные эффекты. Пока жив, даёт **+8 п.п. уклонения** союзникам с тегом `gardens-over-abyss`.
- **Нада:** пассив «Внимание к деталям» даёт **+8 п.п. точности** союзникам с тегом Садов, пока жива. Прежняя общекомандная аура урона по любым дебаффам удалена. Сама Нада получает региональный тег на игровой карточке и в бою.
- **Тег «Сады над пропастью»:** теперь тип `region`, а не `origin`, поскольку утверждённый художественный паспорт **не устанавливает родину Нады**. Биографии не переписывались.
- Старые дополнительные пробные бонусы пассива **игрового Рена** (теговый урон, бессистемная эффективность) удалены; сюжетные `trial-ren`/ `trial-nada` не тронуты.

| Герой | Активное умение | Действие и развитие L1–L6 |
|---|---|---|
| Рен | **Точный удар** | Физический удар, 100/110/120/120/130/140% атаки; с L4 замедление −20% на 1 собственный ход цели, с L6 — на 2 |
| Рен | **Найти брешь** | Одиночный удар 105/115/115/125/125/135%; ослабляет урон атак цели на 2 атаки, с L3 на 3; с L5 CD1 |
| Рен | **Сорвать построение** | Сильный физический удар по одной цели 160/175/175/190/190/205%, CD3. Не понижает сопротивление всей группе, усиливается зацепками через пассив |
| Нада | **Прицельное действие** | Физический удар 80/90/100/110/120/130%; при попадании +1 зацепка |
| Нада | **Найти закономерность** | Физический удар 70/80/80/90/90/100%; +2 зацепки, с L3 +3, CD2, с L5 CD1 |
| Нада | **Разгадать замысел** | Физический **групповой** удар 60/65/65/70/70/75% каждому; +2 зацепки при попадании, с L5 +3; CD3 |

Никакие действия Рена, обычные дебаффы и способности манекенов не добавляют «Просчитанный ход». Все значения — контрольная настройка для игрового испытания, не принятый баланс.
