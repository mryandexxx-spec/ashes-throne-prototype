# Combat-008F-CAMERA — исправление вращения камеры

**Статус:** [В РАЗРАБОТКЕ]. Сборка `v0.3.12 · CBA008F-CAMERA`.

После проверки Combat-008F (`v0.3.11`) владелец сообщил: камера не вращается; ожидание подробной карточки по долгому касанию нужно немного сократить.

## Изменения
- `game.js`: отдельное обработанное по DOM Pointer Events вращение одним пальцем/мышью через `ArcRotateCamera.alpha/beta` и масштабирование двумя пальцами через `radius`. Дублирующий Babylon `ArcRotateCameraPointersInput` отключён через `camera.inputs.removeByType`; камера, её ограничения `beta` и `radius`, колесо мыши и анимации сохранены. На отпускании, отмене указателя, потере захвата и повороте очищается состояние жестов.
- Удержание для всплывающей подробной карточки снижено с **550 до 400 мс**; прежний порог отмены при движении пальца (>12 px) сохранён.
- Выбор цели через `scene.onPointerObservable` не изменён: обычный тап выбирает персонажа, долгое касание открывает карточку без смены цели. Боевые правила не меняются.

## Проверки
- CI `npm test`: регрессия движения указателя реально изменяет `alpha/beta`, отпускание прекращает вращение, два пальца меняют радиус в обе стороны в пределах 12–21, удержание использует 400 мс, сценарии атак/переходов/поворота остаются прежними.
- После появления `v0.3.12 · CBA008F-CAMERA` владелец на iPhone Safari должен проверить: (1) вращение одним пальцем по пустому месту и по персонажу; (2) приближение/отдаление двумя пальцами в пределах существующего зума; (3) короткий тап по врагу выбирает его, а не открывает карточку; (4) удержание ~0.4 с открывает сведения и не выбирает цель; (5) свайп для вращения не открывает карточку; (6) portrait → landscape и повтор; (7) кнопки атаки/автобоя/скорости работают.
- Успешный CI не заменяет проверку на физическом iPhone.

## Риски
Вместо указательного входа Babylon используется ограниченный собственный обработчик вращения и щипка. Требует обязательной мобильной проверки и сравнительной проверки с обычным mouse drag и wheel zoom в браузере. Не утверждать, что конкретная причина неполадки доказана, до теста на устройстве.
