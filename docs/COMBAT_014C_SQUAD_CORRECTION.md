# Combat-014C — исправление назначения лидера и сохранение отряда

**Статус:** [В РАЗРАБОТКЕ] до CI, merge и пользовательской проверки.

## Решение владельца (6 ноября 2026)

**[УТВЕРЖДЕНО]** Вместо ограничения Combat-014B:
1. При первом открытии подготовки отряда (в том числе из кампании) автоматически выставляются **первые пять героев доступного ростера**.
2. Последняя сформированная игроком расстановка сохраняется между входами и перезагрузками страницы.
3. **Любой** персонаж может занимать первую, выделенную лидерскую ячейку. Наличие лидерского навыка **не условие назначения**.
4. Лидерский эффект срабатывает только тогда, когда **именно герой на первом месте** обладает лидерским навыком. У героя без лидерки никаких лидерских бонусов нет; у героя с лидеркой во втором–пятом слоте её эффект не действует.

Решение прямо отменяет утверждённый ранее пункт про «только подходящего лидера» и ограничения четырёх союзников без лидера.

## Техническая реализация

- `game.js`: стандартная расстановка — первые пять элементов `ALLIES`; первый — `selectedLeaderId`, следующие четыре — `selectedPartyIds`. Ровно один слот выделен под лидера. В меню ростера **каждый** герой получает кнопку «В лидеры». Можно сменить лидера, оставив остальных героев в отряде (если новый лидер уже среди них), либо заменить лидера выбранным героем с лавки.
- `CombatCore.createBattle`: лидер — первый живой союзник стартового состава, с явным `leaderId`; способность не требуется. `activeLeaderModifiers` проверяет определение `AbilityData.get(leader,"leader")` и возвращает пустой набор для героя без лидерского навыка. Лидерка другого участника не действует.
- `localStorage`: отдельный ключ `ashes-throne.squad.v1` и версия `1`, поля `leaderId` и `regularIds`; обновляется при изменении состава или назначении лидера. При отсутствии сохранения, повреждённом формате, дублировании ID или исчезнувшем персонаже используется безопасный состав по умолчанию. В Safari с запрещённым хранилищем ошибка перехватывается: отряд можно менять в текущей сессии, но после перезагрузки он вернётся к стандартному.
- Лидерская ячейка остаётся первой и голубой. Если лидер не обладает специальным навыком, это указывается в подсказке и **не блокирует бой**.
- В `AbilityData` у пяти существующих героев `leader` по-прежнему `null`. Способности, новые названия, баланс и правила смерти лидера здесь **не утверждаются**.

## Проверки

Тесты покрывают стартовый состав из пяти, назначение лидером обычного героя, активацию лидерского бонуса только при нахождении обладателя в первой ячейке, перемещение без дублирования, сохранение и перезагрузку, невалидное хранилище, ограничение пяти мест, повтор боя и отсутствие регрессий рендера.
