# Combat-015A — тактический выбор действия автобоя

**Статус:** [В РАЗРАБОТКЕ] — отдельный модуль выбора решения, не подключён к текущему автобою.

## Утверждённое направление
Владелец утвердил умеренно тактическую модель автобоя: учитывать ранения, защиту, количество целей, перезарядки и пользу атак. Основной ручной бой сохраняется.

## Реализация 015A
- `auto-decision.js`: `AutoDecision.chooseAction(battle)` возвращает `{abilityId, targetIndex}` или `null`. Не изменяет `battle`, UI, анимации, таймеры или прогрессию.
- Проверки доступности используют существующий `CombatCore.abilityReady`; сведения о способностях — `AbilityData.get`.
- Допустимы полезное лечение раненого, защита уязвимого без существующей защиты, массовая атака против нескольких целей, усиленная одиночная атака и ослабление при отсутствии эффекта. Иначе — базовая атака. При равных приоритетах выбор стабилен.
- Для единичной атаки применяется цель с минимальным текущим HP, при равенстве — меньший индекс.
- **Временные параметры для технических тестов:** лечение при HP ≤70%; защита при HP ≤60%. Это [ПРЕДЛОЖЕНИЕ], не утверждённый баланс. Отдельные способности, их характеристики и индивидуальные AI-профили не утверждаются.
- 015A **не включает** `auto-decision.js` в `index.html` и не заменяет `CombatCore.performAutoAction`, поэтому опубликованный автобой остаётся прежним. Подключение после оценки — задача Combat-015B.

## Проверка и ограничения
`tests/combat-015a-decision.test.js` проверяет решение без изменения состояния, лечение, защиту, массовые и одиночные атаки, перезарядки, мёртвые цели, fallback, завершённый бой.

Не требуется менять версию опубликованной игры: этот модуль не загружается браузером, UI/основная механика не изменяется. При подключении в Combat-015B поднять версию и код сборки по `docs/AI_WORKFLOW.md`.

**Риск следующего этапа:** существующий движок выбирает цель через `battle.selectedEnemy/selectedAlly`; при интеграции сначала устанавливать цель через `chooseEnemy/chooseAlly`, потом применять существующий `performPlayerAbility`. Проверить отмену автохода и визуальную последовательность.
