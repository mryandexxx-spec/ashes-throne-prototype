# Combat-015D-A — ограниченное внедрение агрессивного ИИ в миссии №2

**Статус:** [В РАЗРАБОТКЕ] до CI, merge, GitHub Pages и приёмки.
**Авторское решение:** [УТВЕРЖДЕНО] — провести **ровно один** эксперимент: `shade` получает профиль `aggressive` только в `demo-mission-2`. Остальные миссии, противники и способности остаются прежними.
**Ожидаемая сборка после merge:** `v0.3.31 · CBA015DA`.

## Изменения
- `mission-data.js`: необязательная конфигурация `enemyAiProfiles: {shade: "aggressive"}` **только** у `demo-mission-2`.
- `game.js`: `enemyForMission(enemy, mission)` создаёт индивидуальную копию шаблона и применяет профиль только в нужном столкновении. Не модифицирует глобальные `HEROES`/`ENEMIES`, сохранения или состав команды. Копии создаются и при подготовке будущих волн, без изменения текущего списка волн.
- `CombatCore`, `EnemyDecision`, `AbilityData` остаются без изменений. У `shade` по-прежнему нет назначенной уникальной специальной или мощной способности: меняется **только цель базовой атаки**, с первого живого союзника на союзника с наименьшим текущим HP. Равенства разрешаются стабильно по индексу.
- `ves`, `ves-2`, `shade-2`, `ves-3` в миссии №2 — без профилей. Миссия №1 и обе волны миссии №3 — без профилей.
- Не изменены HP, ATK, скорость, очередность, награды, требования звёзд, UI и визуальные ресурсы.

## Проверка
`tests/campaign-001-ui.test.js` загружает действующий `EnemyDecision` в браузероподобный сценарий. Проверяются реальные составы для миссий №1/2/3, количество и характеристики врагов, единственный выбранный профиль, отсутствие мутации шаблонов, новый экземпляр для повтора, реальное разрешение инициативы и отличие выбора цели от прежней базовой атаки. Сохранены проверки трёх волн, наград, звёзд, кнопок, фона Safari и логики завершения боя из общей регрессии.

`npm test` включает полный набор проекта. Автоматические тесты не заменяют ручную проверку баланса и Safari. **После merge:** сначала сверить футер `v0.3.31 · CBA015DA`. Затем сравнить миссию №1 (контрольная) с миссией №2, проверить смену слабой цели Теневым клинком, гибель героя, награду/звёзды, повтор, миссию №3 (обе волны), landscape, safe-area и возврат из фона.

## Риски и следующий этап
Даже без повышения характеристик концентрированный урон по раненому герою может повысить смертность. До решения по другим противникам необходимо сравнить на одинаковых составах от 1 до 5 союзников: победу/поражение, погибших, HP, длительность в действиях союзников и звёзды. Не переносить новые профили в сюжетную миссию №1 без отдельного разрешения.
