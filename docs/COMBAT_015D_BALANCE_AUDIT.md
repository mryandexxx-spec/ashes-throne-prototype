# Combat-015D-B — воспроизводимый аудит баланса миссии №2

**Статус:** [В РАЗРАБОТКЕ] — техническое сравнение; не утверждённая настройка игрового баланса.
**Основа:** `main` после PR #85 и #84, `v0.3.31 · CBA015DA`.
**Проверка:** GitHub Actions [42344495578](https://github.com/mryandexxx-spec/ashes-throne-prototype/actions/runs/42344495578), `node-tests` — `success`; исходные результаты выводятся в логах как `BALANCE_AUDIT_JSON`.

## Методика
`tests/combat-015d-balance-comparison.test.js` загружает из **фактических** исходников `HEROES`, `MissionData`, `CombatCore`, `AutoDecision` и `EnemyDecision`. Для каждого состава повторяет одно и то же детерминированное сражение (`demo-mission-2`, пять исходных врагов), меняя **только** наличие `aiProfile: "aggressive"` у `shade`. Значения HP, ATK, speed, умений и состава не меняются.

Составы: `kael`; `kael,lyra`; `kael,lyra,darin`; все пять союзников (`kael,lyra,darin,medic-demo,test-area-damage`). Два режима: `tactical-auto` — актуальный `AutoDecision`; `focused-basic` — скрипт выбирает живого врага с минимальным текущим HP и исполняет только базовую атаку (это **не** поведение человека). Каждая пара дважды пересчитана для проверки детерминизма. Всего 8 сравнительных пар и 32 запуска с учётом повторов.

## Интерпретация и ограничения
1. [ФАКТ] Во всех восьми парах победитель не изменился. В двух парах (полный отряд) осталось больше HP; в одном из них улучшились звёзды и выживаемость.
2. [ВЫВОД] Условная стратегия «бей самого раненого» не гарантирует увеличение сложности. Порядок ходов, роли, поддержка и распределение урона влияют на результат.
3. [ОГРАНИЧЕНИЕ] Это **не** статистическая оценка баланса: нет выборки игроков, вариаций уровня прокачки, порядка героев, ручных решений или разных стартовых состояний. Не делаем утверждений о процентах побед в реальной игре.
4. [ОГРАНИЧЕНИЕ] Тесты выполняют боевое ядро Node.js без Safari, 3D-анимаций, кликов пользователя и реального устройства. Критерий 3★ в миссии №2 (до 9 действий и без смертей) не достигнут ни в одном указанном успешном сценарии.

## Рекомендация
**Сохранить ограниченный пилот Combat-015D-A только в демо-миссии №2; не распространять этот профиль на другие миссии пока.** Для дальнейших решений протестировать дополнительные составы, порядок бойцов и уровни прогрессии, затем согласовать более содержательные тактические роли противников. Не повышать HP/ATK/speed механически для «исправления» результата.

Этот PR добавляет только автоматическую проверку и отчёт. **Никаких изменений опубликованной игры, баланса, умений, миссий, версии или канона.** Слияние требует разрешения владельца.
