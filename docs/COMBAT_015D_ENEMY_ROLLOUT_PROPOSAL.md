# Combat-015D — внедрение профилей противников: план и критерии

**Статус:** [ПРЕДЛОЖЕНИЕ — архив исходного плана]. Ограниченный вариант B (один `shade → aggressive` только в `demo-mission-2`) позднее **утверждён владельцем и технически реализован в PR #85**. Остальные альтернативы и будущие назначения остаются предложениями; этот документ не утверждает дополнительные навыки, характеристики, баланс и правила мира.
**База:** `main` после Combat-015C-B, `v0.3.30 · CBA015CB`, PR #83. Утверждена общая архитектура боевых решений, но не игровые профили конкретных врагов.

## Проверенные исходные данные
- В игровом `HEROES` есть базовые враги `ves` («Вестник Конклава»: HP 90, ATK 18, speed 105) и `shade` («Теневой клинок»: HP 78, ATK 22, speed 135). `ves-2`, `shade-2`, `ves-3` — технические копии с теми же параметрами; это не подтверждение новых персонажей в каноне.
- У этих пяти ID **нет индивидуальных специальных или мощных способностей** в `ability-data.js`; для неизвестного ID действует запасная демонстрационная `special` (удар ×1 с cooldown 2), которая не даёт преимущества перед базовой атакой. Не вводить навыки только ради ролей.
- Первая миссия `black-pass-ambush`: два врага (`ves` и `shade`). Вторая демонстрационная миссия `demo-mission-2`: пять врагов. Третья `demo-mission-3`: сначала два врага, затем `ves-2`, `shade-2`, `ves-3`.
- Звёзды учитывают победу, отсутствие потерь и количество **действий союзников**: 8/9/18 в миссиях 1/2/3 соответственно. Усиление прицельной атаки меняет вероятность получить звёзды даже без правок характеристик.
- Профили `ordinary`, `aggressive`, `guardian`, `support`, `tactical` уже технически существуют. Только у явно помеченного `aiProfile` врага меняется стратегия; текущие шаблоны не помечены.

## Альтернативы
| Вариант | Что меняется | Плюсы | Риски |
|---|---|---|---|
| A — всем дать профиль | `shade` → `aggressive`, `ves` → `ordinary` в общем ростере | Самый малый патч | Затронет все миссии и копии непрозрачно; массовое фокусирование может резко повысить число смертей |
| **B — по миссиям, постепенное включение (рекомендую)** | Миссия 1 остаётся контрольной, в **демо-миссии 2** только один `shade` получает `aggressive`, остальные остаются на старом AI; миссия 3 после проверки | Изолированная проверка одного изменения; есть сравнение с прежней миссией | Нужна безопасная сборка экземпляров врагов из шаблонов без мутации общих объектов |
| C — сразу разные роли + способности | Введение лекарей/защитников и новых умений | Разнообразие сразу | Не утверждены способности, значимо меняется баланс и время боя; слишком рискованно |

## Рекомендованный Combat-015D-A (реализован в PR #85)
1. Добавить в **данные конкретной миссии** необязательную таблицу `enemyAiProfiles` (например `shade: aggressive` только для `demo-mission-2`). Ни одна другая миссия не меняется.
2. В момент создания боя сформировать копии шаблонов противников с опциональным `aiProfile` **только** для данной миссии. Не модифицировать `HEROES`, `ENEMIES`, коллекцию или сохранение отряда.
3. Не добавлять `special`/`powerful` и не повышать HP/ATK/speed. Единственное отличие тестового сценария: Теневой клинок предпочитает противника с наименьшим текущим HP.
4. Покрыть тестами: отсутствие профилей в миссиях 1/3, активация только в миссии 2, сохранение всех параметров, корректные цели, переиспользование шаблона, переход волн, победа/поражение, звёзды, повторы и отложенный показ завершения.
5. Провести сравнение на одинаковых составах: один/три/пять союзников, с автобоем и ручным боем; фиксировать победу, потери, оставшиеся HP, число действий союзников и звёзды. Без доказательств, что сложность не деградировала, **не переносить** профили в сюжетную миссию №1.

## Критерии решения
- Исходная первая сюжетная миссия не изменена.
- Для одинакового состояния и одинаковых действий игрока новая версия детерминирована и не имеет скрытых преимуществ.
- Нельзя получить вражеское действие «из ниоткуда», двойной ход, нарушение cooldown или атаку мёртвого героя.
- Победа/поражение, звёзды, награды и много-волновой переход работают без регрессий.
- При массовой концентрации урона и росте потерь сначала ослабить **поведенческую стратегию**, а не тайно менять характеристики.
- **Пользователь должен отдельно утвердить назначение `shade → aggressive` в демо-миссии 2**, прежде чем менять игровой код.
