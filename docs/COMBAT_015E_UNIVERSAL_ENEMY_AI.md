# Combat-015E — универсальное агрессивное поведение противников

**Статус:** [В РАЗРАБОТКЕ] до успешного CI, merge, GitHub Pages и проверки владельца.
**Решение владельца:** [УТВЕРЖДЕНО] — применять общую агрессивную тактику **ко всем противникам** независимо от их ID и миссии, без индивидуального хардкода.
**Ожидаемая сборка:** `v0.3.32 · CBA015E`.

## Обновление игрового поведения
- `CombatCore.advanceToPlayerTurn` вызывает `EnemyDecision.chooseAction` на каждом ходе любого противника.
- Для противника без явно указанной технической настройки используется **агрессивная тактика по умолчанию**: выбирается доступная полезная атакующая способность; если её нет — базовая атака по живому герою с минимальным **текущим** HP. При равенстве выбор стабилен по индексу в боевом ростере.
- Все действия врага по-прежнему исполняются через общий `performActorAbility` и обычную инициативу; нет новых таймеров или дополнительных ходов.
- В `mission-data.js` удалено `enemyAiProfiles` из миссии №2. `game.js` больше не привязывает ИИ к миссиям или персонажам. Создание копий ростера для боя и волн сохраняется.
- Старые `ordinary`, `guardian`, `support`, `tactical` остаются **техническими** профилями для тестов/будущего дизайна и не назначены реальным персонажам или миссиям. Не утверждаются индивидуальные враги-лекари, защитники или способности.
- HP, ATK, скорость, способности, условия звёзд, награды, герои, уровни и сохранения не меняются.

## Проверки
`npm test`: системные и интеграционные регрессии, включая контроль выбора цели для любых шаблонов и волн, специальные/мощные умения и базовое исполнение, смерть, победу, поражение, рестарт, автодействия. Исследовательские тесты Combat-015D сохраняют **историческое** сравнение в тестовом окружении: `ordinary` для старого поведения всех врагов и `aggressive` только для `shade` в историческом пилоте. Эта тестовая реконструкция не влияет на игру.

Поскольку новое универсальное поведение затрагивает **все** миссии, прежние измерения сложности `v0.3.31` больше не предсказывают баланс `v0.3.32`. Нельзя говорить, что новая сложность проверена реальными игроками. Дальнейшая точная настройка баланса откладывается до Progression Design.

**Мобильная проверка после merge:** версия `v0.3.32 · CBA015E` в футере, миссии №1/2/3, фокус по низкому HP, ручной/автобой, смерть героя, победа/поражение, несколько волн, рестарт, landscape, safe-area, возврат из фона Safari.

Точные формулы силы, пороги миссий и итоговая структура развития остаются [ПРЕДЛОЖЕНИЕ] до отдельного решения.
