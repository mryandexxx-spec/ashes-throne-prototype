# COMBAT-ENV-011 — единая композиция природного ущелья

**Дата:** 9 ноября 2026. **Статус:** [ПРЕДЛОЖЕНИЕ] / [В РАЗРАБОТКЕ]. Не канон. Художественная приёмка не пройдена.

## Исходная точка
ENV010 v15, слитый PR #174, игровой main 170c451dcff449271d51f11e6108a05583dd0fb5. В ENV010 старое дно начиналось с глубины d=26 и примерно y=-114: обзор закрыт задней частью боевого уступа. Подъём дальнего хребта давал неестественный навес, поэтому **не используется**.

## Единственная новая постановка без цикла проб
- Сохранены фиксированная **перспектива** 3/4, alpha=-3π/4, beta=.96, radius=12, pinch 12–21, расположение бойцов и все правила/сохранения.
- Отдельный визуальный модуль ENV011 слегка понижает только дальний, неигровой край ENV009. Центральная зона бойцов y=0 не изменяется.
- Один авторский GLB `assets/env011/open-gorge-v1.glb`: два пространственно сопряжённых склона, осыпной переход, открытое S-образное дно (примерно y=-3.7 при d=9 → y=-43 при d=120) и низкий удалённый геологический план. **4 меша, 11 180 треугольников, менее 400 KB**.
- Источник GLB `tools/env011-gorge-export.cjs`: детерминированный кодовый скульпт **без Blender**. Не добавляется runtime-зависимость, новый Engine/Scene или цикл отрисовки.
- Импортёр ENV010 сначала валидирует ENV011 и при неудаче возвращается к **ENV010 v15**, а затем к процедурному fallback.
- Материалы Rock063 CC0 512×512 повторно используются.

## Проверки и художественный критерий
- Node CI: синтаксис, имеющиеся регрессии, детерминированная сборка и общие геометрические границы; считать успешными только после фактического прогона.
- Настоящий Chromium Babylon.js WebGL из GitHub Actions: **ENV010 default/far vs ENV011 default/far**, затем полный HUD 844×390, pinch/автобой/повтор. Артефакты с реальными кадрами и итоговая критика обязательны **до согласования merge**.
- Не принимать, если дно снова не видно, скалы образуют навес/тонкие парящие крылья, фон обрезан краями, бойцы/индикаторы перекрыты.
- **Не проверено:** физический iPhone Safari, FPS/GPU/нагрев, долговременная сессия, все варианты боя на устройстве.
