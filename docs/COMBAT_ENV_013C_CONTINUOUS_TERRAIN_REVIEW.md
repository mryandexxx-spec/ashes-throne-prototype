# COMBAT-ENV-013C — третья ограниченная 3D-итерация / непрерывный скальный рельеф

**Статус: [В РАЗРАБОТКЕ], [ПРЕДЛОЖЕНИЕ].** 9 ноября 2026. Новая проба выполнена по новому разрешению владельца «Ещё итерацию». Не канон географии Садов над пропастью.

## Метод — отличается от отвергнутых ENV013 и ENV013B

**Проблема:** первый кандидат образовал каменный навес, второй — изолированную скальную плиту и отдельные плоские «коробки» по периметру. Регулировка высот не изменила принципа формы.

**Кандидат ENV013C:** одна связанная система рельефа от фактической кромки ENV009:
- левый берег продолжает существующий край от (r=.945) через существующие высотные точки (r=1.25, 1.43, 1.66, 1.91, 2.42) и расширяется за границу кадра, вместо отдельно стоящего симметричного массива;
- правый берег уходит вниз как протяжённая наклонная скальная поверхность, чтобы под ним ощущалась глубина;
- одна непрерывная удалённая противоположная стена и ещё более дальний, приглушённый атмосферой план; никаких замкнутых гранёных объёмов с видимыми торцами;
- фототекстура верха уступа Rock063 (CC0) сохранена из предыдущего кандидата, переход к обрыву мягкий.

Все поверхности настоящие Babylon Mesh + VertexData, с треугольниками, нормалями, UV, локальными scene-owned ресурсами. Никакой отдельной камеры, сцены, движка или render loop. Никакой генерации случайных гор по кадрам, архитектуры, магических предметов, рек или мостов.

## Инварианты

Нет изменений CombatCore, боевого AI, позиций бойцов, урона, экономики, сохранений, canvas touch, камеры alpha=-3π/4/beta=.96, pinch 12..21, HUD. Действующий ENV010 baseline доступен по QA-переключателю `?arena=env010`; при ошибке ENV013C прежний fallback ENV010.

Номер этого **неопубликованного** кандидата — `v0.3.85 · ENV013C`; актуальная публикация остаётся `main`.

## Проверка / приёмка

CI: Node-тесты, Chromium/Babylon настоящие сцены default/far, два полных HUD 844×390, синтетические pinch, 4×, автобой, завершение и повтор боя; Github Actions captures в `docs/evidence/env013c/` после успешного workflow.

**Художественный итог:** только по реальным PNG, не по расчётам вершин. Критерии — отсутствие скальных крыш, естественное соединение с площадкой, ощущение большой глубины справа, не плоские скалы, читаемый HUD. Если художественно хуже/неубедительно — остановиться на этом кандидате, не плодить четвёртый без нового решения.

**Непроверено:** физический iPhone Safari, fps, нагрев и реальные жесты. Не сливать ни этот PR, ни зависимые #183/#185 без разрешения владельца.
