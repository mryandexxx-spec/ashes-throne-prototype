# ENV022 — временная художественная подложка боевой арены

**Статус: [В РАЗРАБОТКЕ / ПРЕДЛОЖЕНИЕ].** Технический эксперимент, не финальный 3D-ландшафт, не канон географии.

## Что делает
- По обычному адресу игры (без параметров) загружает **наше второе clay-концепт-изображение** ущелья как плоскую фоновую иллюстрацию.
- Фон хранится локально, в `assets/env022-canyon-concept.svg` (WebP 480×222 внутри SVG, приблизительно 6 КБ), не требует сети, кроме загрузки игры.
- В этом режиме по умолчанию WebGL-холст прозрачный, статичные сценические меши CV/ENV009/ENV017 не создаются. **Бойцы, выбор цели, эффекты попаданий, анимация, HUD, бой и pinch остаются в настоящем Babylon.js.**
- Прежняя 3D-арена доступна через `?environment=env017`, вариант ENV010 — через `?environment=env010`. `?environment=concept` также продолжает работать.
- Изображение не следует перспективе при pinch-zoom, поэтому некорректно выдавать такое решение за настоящее 3D или совпадающий перспективный рендер.

## Изменения
- `assets/env022-canyon-concept.svg` — художественная заглушка из генерации в разговоре, сжата для мобильного превью. Это исходное художественное предложение без утверждения нового канона.
- `game.js` — opt-in флаг, прозрачный Babylon Engine/Scene, сохранение штатного рендера и hit-testing.
- `combat-visual-007.js` — пропуск создания сценической геометрии при флаге, с сохранением пула боевых FX.
- `styles.css` — подложка лишь в `#battle.env022-concept-preview`.
- `package.json` и `index.html` — согласованный код сборки `v0.3.92 · ENV022-CONCEPT`.
- `tests/env022-concept-art.test.js` — проверка встроенного WebP, переключателя, отсутствия 3D-сценографии в режиме заглушки и доступности FX.

## Не изменяется
Боевая логика, GDD, GDD-камера и её диапазон, модели бойцов, интерактивность HUD, механика и приватный архив вселенной. Без слияния PR новая иллюстрация **не появится в публичной игре**.

## Проверки и риски
- Выполнить `npm test` в GitHub CI; этот пункт подтверждать лишь после реального зелёного job.
- Проверить настоящий WebGL с full HUD на 844×390, ручной выбор и подсветку цели, удары, победу/поражение, 1×/4×, повтор, pinch 12–21, фоновые события вкладки. **Не утверждать браузерный тест без его реального прогона.**
- Возможные проблемы: WebGL alpha на iPhone Safari; SVG с embedded WebP; перспективное несовпадение при pinch; 480px может казаться мягкой на Retina. При ошибке откат — убрать `?environment=concept`.
- На реальном iPhone проверить: (1) версию `v0.3.92 · ENV022-CONCEPT` в футере вне боя; (2) заглушку в landscape; (3) 3D-бойцов над фоном; (4) выбор целей/удары; (5) pinch и повторный бой; (6) прокрутку/ориентацию/safe-area.

**Слияние запрещено без прямого разрешения владельца на конкретный PR.** Восприятие композиции в концепт-картинке не является приёмкой нового runtime-бэкграунда.

## Исправление ENV022-DEFAULT

**[В РАЗРАБОТКЕ]** В PR исходный opt-in режим изменён на default: обычный URL игры должен выводить иллюстрацию в бою. Причина исправления — пользователь увидел старую 3D-арену, потому что ранее требовался специальный URL. Проверка по умолчанию использует настоящую страницу `index.html` **без** query. Сборка-кандидат `v0.3.93 · ENV022-DEFAULT`. Переключатели `?environment=env017` / `?environment=env010` сохраняют прежние сцены. Состояние GitHub Pages и iPhone подтверждать отдельно.
