# ENV022 — готовое CC0 плато с природной боевой площадкой

**Статус: [ПРЕДЛОЖЕНИЕ], [ТЕХНИЧЕСКИ ПРОВЕРЕНО], [ХУДОЖЕСТВЕННО ОТКЛОНЕНО].** PR #209 Draft — не сливать.

## Источники

Готовые внешние ассеты из одного совместимого набора Grab3D Cozy Terrain Kit, заявлены издателем как **CC0**:
- [Mesa](https://grab3d.com/models/nature/mesa/) — единая скальная масса с верхним травянистым плато, ~17k исходных треугольников;
- [Cliff Face](https://grab3d.com/models/nature/cliff-face/) — сопряжение края;
- [Canyon Wall](https://grab3d.com/models/nature/canyon-wall/) — удалённый берег.

Исходные GLB скачаны напрямую GitHub Actions, структура/размеры/реальные полигональные меши проверены; `assets/env022/source` хранит исходники. С помощью `tools/env022-prepare-cc0-terrain.py` треугольники **оригинальных готовых моделей упрощены**, настоящие цвета из embedded baseColorTexture запечены в vertex colors. Результат: `MesaTerrain.glb` 249160 B / 10500 triangles, `CliffFace.glb` 133844 B / 5500, `CanyonWall.glb` 169896 B / 6999. Новых внешних зависимостей в игровом runtime нет; Python-библиотеки только в GitHub Actions.

## Реализация и проверки

`combat-environment-017.js` импортирует готовые GLB локально, принимает заранее заданные положения 3 объектов относительно фиксированной камеры и **только после успешной полной загрузки** скрывает старую овальную `ENV009 living_ledge`, `ravine` и дальние кольца. Персонажи, камера, HUD, CombatCore, штаб и ENV010 fallback не менялись. При ошибке загрузки прежнее окружение остаётся доступным; не создаётся второй render loop.

[GitHub Actions run](https://github.com/mryandexxx-spec/ashes-throne-prototype/actions/runs/42706880918): **208/208 Node tests PASS**, настоящий Chromium Babylon WebGL full game/HUD **844×390** радиусы 12/19 **PASS**, маркер `env022Integrated=ready`, три импортированных meshes и выключенная старая платформа. [Реальные PNG и HTML DOM](https://github.com/mryandexxx-spec/ashes-throne-prototype/actions/runs/42706880918/artifacts/13713464274).

## Художественный итог

На реальных кадрах бойцы находятся на верхнем плато готовой модели Mesa, а прежний овальный остров действительно скрыт. Это впервые меняет несущую поверхность на **готовый внешний массив**, а не оставляет отдельные камни возле старой площадки.

Однако объекты по-прежнему читаются как отдельное зелёное столовое плато слева/в центре и отдельный высокий геометричный борт справа. Ущелье не выглядит одной природной формацией. Вторая корректировка сопряжения не преодолела проблему. **[ART REJECTED]**: не сливать в main и не компенсировать проблему декоративной геометрией.

Вывод: перейти к поиску **готовой цельной конфигурации ущелья** с двумя связанными геологическими бортами, а не сшивать не предназначенные друг для друга ассеты. Кандидат для изучения: внешняя Continuous Gorge Escarpment Configuration (3DAssets.dev), требует проверки лицензии, геометрии, совместимости и мобильного бюджета. Никакой канон мира не изменён. На физическом iPhone Safari, FPS, жесты и полный бой не проверялись.
