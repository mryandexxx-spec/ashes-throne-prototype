# ENV026 — авторская Blender-композиция из настоящих готовых CC0-ассетов

**[ПРЕДЛОЖЕНИЕ / В РАЗРАБОТКЕ]**. Только [Draft PR #217](https://github.com/mryandexxx-spec/ashes-throne-prototype/pull/217). Ни `main`, ни география канонического мира не затронуты.

## Задача и источник истины

По утверждённому владельцем брифу `docs/COMBAT_ENV_013_APPROVED_ART_DIRECTION.md`: в кадре **реальной** фиксированной камеры 844×390 со всеми элементами HUD должны читаться естественная полка с бойцами, большой обрыв, открытая пустота справа и отделённый дальний берег. Не требовать видимого дна/реки/руин/мостов. Не изменять CombatCore, актёрские координаты, zoom, camera yaw/beta, HUD или персонажей.

Вместо алгоритмических лент используется **редактируемая Blender-сцена из настоящих опубликованных скал Poly Haven**:
- [Coastal Cliff 04](https://polyhaven.com/a/coastal_cliff_04), CC0; из подтверждённой ENV025 модели 40k / 827400 байт, исходные фото-цвета.
- [Coastal Cliff 02](https://polyhaven.com/a/coastal_cliff_02), CC0; из подтверждённой ENV021 модели 11k / ~230k байт, исходные фото-цвета.

## Авторская сборка

`tools/env026-author-gorge.blend.py` исполняется headless Blender в GitHub Actions. Он импортирует именно оригинальные source-derived GLB, применяет настоящие исходные transform matrices, вручную задаёт архитектуру кадра:
1. Авторская центральная ближняя скальная полка и массив слева, со скальным краем, ограниченным справа.
2. Дальний берег, созданный из отдельного экземпляра натуральной скалы, пространственно отделённого реальной пустотой.
3. Левый корневой скальный массив из другого готового Poly Haven ассета для перехода от боевой зоны к суше.

Геометрия **не генерируется алгоритмически**: часть исходных face-ов отсечена, но новые ландшафтные треугольники не создаются, между двумя берегами нет пола ущелья. Редактируемые объекты и reference-камеры, согласованные по реальным alpha/beta/radius/FOV, сохраняются в `assets/env026/ENV026_authored_gorge.blend`; в игру экспортируется `assets/env026/ENV026_authored_gorge.glb` как единая статическая сетка с оригинальными source-derived фотоцветами.

Первый фактический Blender экспорт показал **37125 треугольников, 1 меш, 4 455 952 байта**, три геологические части 6190 + 19945 + 10990 треугольников. Исходно workflow сборки ошибочно ожидал несколько мешей после join (блокер в самой инспекции; файлы успешно получены), затем это исправлено. Бинарники из выполненного GitHub Actions экспортного задания сохранены через проверенный recovery-workflow. Это **не художественная приёмка**.

## Обязательные проверки перед следующим решением

- Node `npm test` с текущими файлами и валидной проверкой GLB.
- Реальный Chromium Babylon WebGL полный HUD 844×390 radius 12/19 в игровой сцене, без подмены скриншота Blender-рендером.
- Строгая геометрическая опора всех шести бойцов на **ближнем исходном** скальном массиве (не на коллайдере/старой скрытой арене).
- Отдельный художественный вердикт для каждого кадра: открыт ли просвет, не занавешивает ли дальний берег персонажей и HUD, виден ли обрыв, нет ли искусственного прямого среза на кромке или плоской ширмы.
- Производительность, повтор боя/контакты и iPhone Safari не считаются проверенными только по успешной автоматизации.
