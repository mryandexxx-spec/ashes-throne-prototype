# Combat-Waves-001 — технический каркас волн

**Статус: [В РАЗРАБОТКЕ].** Механизм и третья демонстрационная миссия находятся в PR, ещё не слиты, не опубликованы и не проверены владельцем на iPhone. Правило сохранения состояния союзников между волнами **[УТВЕРЖДЕНО владельцем 06.11.2026]**. Тестовое условие 3★ третьей миссии (≤18 действий) — **[ПРЕДЛОЖЕНИЕ]** для проверки, не утверждённый игровой баланс. Это не изменение сюжетного канона.

## Контракт

- Старый вызов `CombatCore.createBattle(lineup)` работает по-прежнему: одна волна и победа после уничтожения всех её врагов.
- Дополнительно можно вызвать `CombatCore.createBattle(lineup, futureWaves)`, где `futureWaves` — массив непустых массивов шаблонов врагов; возможны 1, 2, 3 и более волн, с разными размерами.
- В каталоге миссий для будущего использования допускается **необязательное** свойство `futureEnemyWaves: [[enemyId, ...], ...]`; `game.js` разрешает эти ID через уже существующий тестовый каталог `ENEMIES`. В первой и второй миссиях это свойство отсутствует, поэтому их принятый баланс остаётся прежним. Только третья демонстрационная миссия содержит одну дополнительную волну.
- Когда последняя цель текущей волны побеждена, следующие враги появляются автоматически, **без промежуточной победы и награды**. Сражение завершается только после последней волны.
- Между волнами сохраняются HP союзников, шкала инициативы, перезарядки, ослабления/защиты и общий `allyActions`. Враги новой волны появляются со свежими HP, инициативой 0 и без эффектов. Это правило сохранения состояния между волнами утверждено владельцем для технического каркаса 6 ноября 2026 года.
- В журнал событий добавляется `wave-start`, в интерфейсе боя показывается `Волна N/M`, только если волн больше одной.
- Поражение отряда завершает бой немедленно; следующая волна не запускается. Награда и звёзды рассчитываются один раз **после** окончательной победы; одна система звёзд на всю миссию.

## Ограничения

- Добавлена **третья демонстрационная миссия**, которая открывается после победы во второй: первая волна — 2 существующих противника, вторая — 3 других существующих тестовых противника. Сюжет только текстовая заглушка. Первая и вторая миссии не изменены.
- 3D-сцена пока готовит меши из фиксированного массива `HEROES`: будущие волны должны использовать зарегистрированные шаблоны, либо понадобится отдельная безопасная система динамических мешей.
- Переход между волнами происходит без паузы и анимации. Смена состава и счётчик проверяются автоматизированными тестами; Safari/iPhone и реальная серия волн в браузере ещё не проверены.
- При повторении одного enemyId **в разных волнах** его предыдущая единица удаляется и создаётся новая; уникальность ID обязательна **внутри каждой** волны.
- Нет сохранения незавершённого боя и серверной инфраструктуры. Система сохранения прогресса и баланс существующих миссий не изменены.

## Проверки

`tests/combat-waves-001.test.js`: одна/две/три волны, разные количества врагов, накопление действий, сохранение выживших союзников, цель и очередь после смены состава, отсутствие промежуточной награды/победы, финальная награда один раз, поражение до второй волны, проверка неверных данных и регрессия старого API.

Третья миссия — чисто тестовая: 1★ победа во всех волнах, 2★ без потерь, 3★ без потерь за не более 18 действий союзников **в сумме за обе волны**. Порог 18 выбран как временная проверочная настройка и требует отдельной оценки баланса. Награда та же +1 учебный материал после финальной победы и через симуляцию после 3★. Билд `v0.2.6 · CW001`.

Перед приёмкой проверить на iPhone: открытие третьей после второй, два и три врага по волнам, переход с сохранением HP/эффектов, отсутствие промежуточной награды, финальный результат и начисление +1, повтор, перезагрузка сохранения и футер. Никаких новых сюжетных сущностей в PR.
