# Combat-001 — ручные проверки математической модели

Модуль `initiative-model.js` **пока не подключается** к игре. Запустить тест можно в Node.js командой `node tests/initiative-model.test.js`; это не требует Babylon.js, сети или сборщика.

```text
speed 100 vs 200, обе шкалы стартуют с 0:
t=5   fast
t=10  slow, затем fast (индекс slow меньше индекса fast)
t=15  fast
t=20  slow, затем fast
t=25  fast
t=30  slow, затем fast
30 действий: slow = 10, fast = 20
```

При равной скорости 100 оба достигают порога в t=10: сначала участник с меньшим индексом, затем второй **без продвижения времени**. Погибшие персонажи не накапливают инициативу.

Не проверено: интеграция с реальным боевым UI, эффекты скорости, воскрешение, автобой, iPhone/GPU (в этой задаче UI не менялся).
