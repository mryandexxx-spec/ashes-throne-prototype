# FIRSTPLAY007 — персонажи внутри сюжетных кадров

**Статус:** [В РАЗРАБОТКЕ], художественная серия [ПРЕДЛОЖЕНИЕ]. Этот PR **не готов к слиянию**, пока семь WebP-ресурсов не добавлены в `assets/cutscenes/first-report/v5/` и не пройден CI.

## Задача владельца
Не увеличивать портреты. Игрок должен **видеть людей внутри каждой иллюстрации**, взаимодействующими с повреждённым мостом, а не читать реплики на красивом безлюдном фоне.

## Постановочная последовательность
| Beat | Файл в v5 | Действие |
| --- | --- | --- |
| 0 · рабочие | `warning.webp` | Рабочие пытаются удержать разрушенный переход |
| 1 · мастер | `conflict.webp` | Мастер требует прекратить работы и снять людей |
| 2 · Арт | `art-support.webp` | Арт указывает на снятый крепёж у опоры |
| 3 · Рен | `ren-route.webp` | Рен показывает сохранившуюся нижнюю лестницу |
| 4 · решение | `decision.webp` | Рен, Арт, мастер и рабочие одновременно присутствуют в кадре |
| после приказа | `art-support.webp` или `ren-route.webp` | Визуальная реакция на выбранный приказ |
| после боя | существующий `v2/aftermath` | Отчёт/общая сюжетная улика, после подтверждённой победы |

Портреты гражданских — `worker-portrait.webp` и `master-portrait.webp`, отдельно вырезанные из тех же иллюстраций. Подлинные игровые портреты Арта и Рена остаются без изменений.

## Поведение и UX
Вступление, выбор, бой, поражение/повтор, итог и завершение полностью остаются у `FirstPlayCore` и `FirstPlayStoryCore`. Приказ `survey` даёт Арту +30 скорости, `cover` даёт Рену +35 Protection; числа не меняются. `skip` не пропускает обязательные выбор и бой. Камера приближает только 2–5%, чтобы не вырезать нарисованных персонажей. Преференция уменьшенной анимации уважается. В Safari необходимо сбрасывать srcset предыдущего AVIF, если новый кадр хранится только в WebP.

## Технический пакет
- Пять изображений 1672×941, WebP (около 175–210 КБ на кадр) и два портрета 224×224.
- Предусмотрены необязательные мобильные версии 1100×620 для будущего адаптивного `<picture>`; текущая реализация использует оригинальные WebP.
- Источники — сгенерированные художественные предложения текущего диалога, не установленный канон и не лицензированные фотографии людей.
- Каждая картинка заменяется отдельным файлом, без правок боевой логики.

## Критические условия PR
**Нельзя сливать PR с отсутствующими v5-изображениями.** Подготовленный пакет находится в артефакте этого диалога, не в GitHub, потому что доступный GitHub connector может записывать текст, но не переносит бинарные файлы из контейнера по `source_file_ref`. По факту загрузки требуется прогнать Node и сквозные WebKit/Chromium: выборы, бой, поражение, победа, повтор, сохранение, сброс, отсутствие боковой прокрутки и визуальное появление людей в кадре. Реальный iPhone Safari — отдельная приёмка.

## Критика
Генеративные изображения могут немного отличаться по лицам и костюмам между кадрами. Перед художественной приёмкой сравнить с утверждённой внешностью Рена/Арта и при необходимости заменить конкретные кадры, не выдавать изображения за канон рассказа. Не считать смену рисунков покадровой анимацией тел.
