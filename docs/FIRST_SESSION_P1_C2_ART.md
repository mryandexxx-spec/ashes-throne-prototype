## Постановка
Прежний A3 повторял аварию и не показывал отказ/преграду, старый B1 показывал мастера в другом костюме, мост выглядел восстановленным. Новая серия: A3 — мастер пытается остановить демонтаж, сборщик действует у крепления, страж закрывает каменную лестницу; B1 — люди на безопасной каменной площадке, поддерживают друг друга, мост повреждён; B3 — отдельный крупный план мастера с листом, содержание документа остаётся читаемым DOM, не частью рисунка. Две неудачные генерации с посторонним сюжетом отбракованы. Из A3 удалены случайные эмблемы при подготовке ассета. Охранник визуально условный: костюм не идентичен инвентарю npc-pass-guard; это не новая фракция и не утверждённый облик. Рен/Арт сопоставлены с действующими игровыми портретами, сходство не пиксельно точное. Мастер/место/мост согласованы между кадрами. Приватная проза и биографии не изменены и не публикуются.

## Интеграция
- Сохраняются четыре вводных beat, 15,5 с чтения до последнего кадра, явная кнопка входа в реальный бой, прежние сохранения/ветки, победа/поражение и вся механика. A1, диагностика и маршрут пока используют v5, не утверждать полную замену каждого кадра контракта.
- Текст мастера и Арта уточнён, а не расширен. Документ — отдельный план; звук прежний: conflict/rescue/document, без autoplay; P1-C1 не заменяется. Повторный монтаж сохраняет старый reduced motion/skip.
- Один ближайший WebP предзагружается после текущего кадра; не предзагружаем развязку перед победой; ссылка освобождается при выходе. При ошибке изображения убирается предыдущий кадр, текст остаётся. Нет нового Engine/Scene и зависимостей.
- Для новых кадров снято дополнительное масштабирование, позиция 20%/35%; компактный нижний ряд на landscape ≥620px, карточка документа справа, чтобы не закрывать мастера. Изолированный Chromium-макет с существенными правилами CSS проверен на 844×390, 932×430, 844×320 (9 комбинаций), без переполнения, с кнопками ≥44 px и без перекрытия шапки. На 844×320 высота свободной области увеличилась на 48–80 px. Это не сквозной прогон реальной игры; портреты в локальном макете не загружались.
- Node проверяет существование всех файлов, заголовок RIFF/WEBP, бюджет, три ветки и отдельные rescue/document; browser checks отсутствие наложения шапки/футера, фактическое декодирование и сохраняют скриншоты новых сцен.
