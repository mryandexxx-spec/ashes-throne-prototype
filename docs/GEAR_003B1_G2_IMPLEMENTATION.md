# Gear-003B1 — полный тестовый G2

**Статус: [В РАЗРАБОТКЕ]**; ветка открывается как PR, **не сливать без разрешения владельца**. Основание: шесть решений Gear-003G (пп. 42–47 в `game-design/progression/DECISIONS.md`, приватный проектный PR #10).

## Объём B1
- Сохранён рабочий G1 и чистый старт героев, при котором первоначальный `ashes-throne.progress.v2` остаётся резервной копией.
- Добавлены **12 тестовых G2 предметов**, разрешённые классы и рецепты из рабочего каталога ред. 0.4; три базовых вида оружия, две категории корпуса/головы/рук/ног и общий пояс.
- G2 стоит **2000 валюты** за шесть установок. Переход G1 6/6→G2 0/6 стоит **250 валюты**, добавляет **HP +3% и ATK +3%**, бонусы и установленные предметы G1 остаются в истории.
- G2 6/6 добавляет к накопленной силе **+6% HP и +6% ATK** (тем же слотовым распределением, что у G1). Итоговый вклад экипировки после перехода и полного G2 — +15% HP и ATK. Скорость не меняется. **G2→G3 специально заблокирован**, поскольку G3-код не разрешён.
- Версия v3 сохраняет `gear.tier` и `installedByTier["1"], installedByTier["2"]` с ID всех предметов и полностью проверяет историю перед загрузкой/записью. Нельзя подменить старые предметы несуществующими или чужими классу, нельзя оплатить переход до 6/6. Старые v3 G1 остаются читаемыми.
- Для теста G2 кнопка «Тестовые ресурсы» поднимает базовое сырьё до `Fe24,Le32,Cl67,Wo10,Fa24,Th20,Gl2`, как только хотя бы один герой открыл G2. Для остальных героев G1 прежние минимумы не уменьшаются. Эти суммы не означают баланса настоящего фарма.
- Экран героя показывает текущий G, рецепт, материалы, бонус, возможность отдельного перехода; ошибки записи откатывают в памяти покупку или переход.

## За пределами разрешения
- G3: только исследования, ни одного G3 itemId/рецепта/перехода в коде не добавлено.
- Не реализовывались добыча семи материалов в миссиях, магазин, реальный баланс энергии или 14 боевых формул.
- Не изменялись `combat-core.js`, уникальные способности, кампания, система состава команды. Временные цены не равны финальной экономике.
- Старый материал C не конвертируется и не расходуется на новые G2 вещи.

## Тесты и приёмка
- `tests/gear-003b1-g2.test.js`: независимое сравнение всех 12 составов G2 ред. 0.4, расчёт потребности на пять комплектов **168 сырьевых единиц**, по одному доступному предмету на слот в пяти классах, G1→G2, сохранение истории и +3% за переход, G2 полный +6%/+6%, запрет G3, стекло, два окна, повреждённый v3 и перезагрузка.
- `npm test` включает все существующие тесты боя, кампании, G1, миграции и базового интерфейса. Результат GitHub Actions считать проверенным **только после успешного CI**; проверку на iPhone не имитировать.
