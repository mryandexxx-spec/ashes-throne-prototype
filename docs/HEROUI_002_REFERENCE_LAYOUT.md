# HEROUI-002 — схематическая карточка героя по визуальному референсу

**Дата:** 8 ноября 2026. **Статус:** [В РАЗРАБОТКЕ], отдельный игровой PR, не в `main`.

## Источник решения

Владелец приложил изображение с горизонтальной карточкой героя: слева умения, в центре герой и слоты экипировки, справа уровень/прогресс, со свободным пространством под развитие. При этом прямо уточнил: **3D-модели пока не нужны, визуальный пример использовать схематически**.

Изображение — композиционный референс, **не источник канона**: имя, семизвёздная система, осколки, классы, валюта, цены и сцена с референса в проект не переносятся.

## Реализация

- **Лево:** пять существующих способностей из `AbilityData`; короткие названия сразу видны, описание/цель/перезарядка раскрываются нажатием. Игровая логика не меняется.
- **Центр:** схематический человекообразный силуэт, созданный CSS, без Babylon.js, текстур, загрузки моделей и внешних изображений. Небольшая эмблема героя берётся из существующего `glyph`. Под ним — все шесть реальных слотов экипировки и существующая кнопка изготовления/установки или повышения G-ступени; прежние затраты и блокировки сохранены.
- **Право:** доступный максимум уровня, стоимость повышения, кнопка повышения, действующие характеристики и 14-статный справочник. Никаких звёзд, осколков и других пока не реализованных интерактивных механик.
- **Мобильность:** три колонки в landscape; компактные отступы, безопасный перенос текста и прокрутка страницы; portrait — последовательная вертикальная компоновка. Ориентация и safe-area наследуются из существующего интерфейса.
- **Важное:** существующие DOM ID сохранены, чтобы не ломать обработчики `gearEquipNext`, `detailUpgrade`, `gearSlots`, навигацию, сохранение и боевой контур.

## Проверки

- Автоматический тест структуры `tests/hero-ui-002-reference-layout.test.js`: порядок колонок, сохранение ID, доступность кнопок, версия в футере.
- Полный штатный набор Node-тестов, проверки синтаксиса, GitHub CI.
- После разрешения на merge и успешной публикации: iPhone Safari landscape, прокрутка карточки, доступность всех шести слотов, раскрытие умения касанием, повышение уровня/экипировка, возврат в список, переход в кампанию и бой.

**Граница:** этот PR не добавляет модель героя и не утверждает пользовательские характеристики/культуру персонажа по стороннему скриншоту. Следующая доработка — только после отдельной приёмки владельца.
