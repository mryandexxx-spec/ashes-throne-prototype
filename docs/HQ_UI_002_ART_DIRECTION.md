# HQ-UI-002 — художественное оформление главного меню

**Статус:** [В РАЗРАБОТКЕ] — оформление кандидата на проверку. Арт-макет принят как визуальный ориентир, но не как игровая логика или канон.

## Что изменено

- Профиль, ресурсы, верхний HUD и нижняя навигация получили тёмный металл, древесно-коричневые оттенки и золотые акценты вместо однотонного зелёного интерфейса.
- Четыре станции оформлены как полупрозрачные панели с золотыми заголовками, гербовыми пиктограммами, стрелками, шкалами и кнопками. Все существующие маршруты, DOM ID и реальные показатели сохранены.
- Никакие числа, уровни, валюты, персонажи или сроки, нарисованные на иллюстративном макете, не были перенесены как игровые факты.
- Для HQ-UI-003 подготовлена отдельная чистая панорама без HUD: `hq-hall-painting.webp` (2048×688, 151 364 байта) и `hq-hall-painting-mobile.webp` (1280×430, 65 992 байта), однако **WebP ещё не загружены в GitHub**. CSS уже поддерживает эти файлы и сохраняет прежнюю SVG-сцену резервным слоем. Следовательно, в этом PR пока нельзя считать живописную графику интегрированной или опубликованной.
- Код боя, экономики, сохранений и наград не изменён.

## Следующий художественный проход

**[ПОДГОТОВЛЕНО ЛОКАЛЬНО]** Чистая панорама, четыре участка (отряд, карта, разведка, оружейная зона), две сжатые версии WebP и автономная примерка. **[ОЖИДАЕТ ЗАГРУЗКИ]** Поместить оба файла в `assets/` той же ветки `feat/hq-ui-002-art-direction` (посредством веб-интерфейса GitHub: Add file → Upload files) и лишь затем тестировать показ реального WebP в браузере. Исходный комплект: `HQ_UI_003_Art_Preview.zip`, подготовленный в беседе. Персонажи, эмблемы и сюжетные детали не становятся каноном автоматически.

## Проверки перед слиянием

1. CI регрессий и landscape smoke (844×390, 932×430).
2. Не должно быть горизонтального overflow у страницы (прокручивается только панорама), clipped кнопок, пересечений с safe-area и ложных данных.
3. Свайп по залу, кликабельность всех четырёх панелей и всех пяти нижних кнопок, «Ещё», ежедневные награды, переходы и возврат.
4. Ручная проверка на физическом iPhone Safari landscape; скриншот и художественная приёмка.

## HQ-UI-003 — подключение чистой иллюстрации

- CSS задаёт ширину сцены `max(1250px,330dvh)` и горизонтальную панораму; `cover` сохраняет пропорции исходного рисунка.
- `image-set(1x mobile, 2x full)` выбирает подходящий источник по плотности пикселей.
- SVG остаётся нижним запасным слоем, поэтому отсутствие WebP не оставляет пустой штаб.
- Координаты станций: 4%, 28%, 53%, 76% от ширины сцены.
- **Риски:** пока WebP отсутствуют, браузер вправе сообщать об их 404; до загрузки их нельзя считать принятыми. Некоторые элементы иллюстрации являются неканоническими; пользователь должен проверить их художественно.
- После загрузки сделать скриншоты 844×390 и 932×430, проверить вес/время загрузки, iPhone Safari landscape, свайп, тап, переходы, safe-area и возврат. Проверка в CI без файлов доказывает только сохранность запасного слоя.
