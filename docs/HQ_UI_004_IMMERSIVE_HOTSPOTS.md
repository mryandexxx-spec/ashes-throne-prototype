# HQ-UI-004 — интерактивные предметы панорамы

**Статус:** [В РАЗРАБОТКЕ] — предложение к художественной и мобильной приёмке владельцем. Новых фактов канона нет.

## Решение

Из HQ-UI-003 убраны четыре крупные полупрозрачные карточки. Теперь интерактивным элементом служит сам объект сцены:

| Объект в иллюстрации | Подпись внутри сцены | Существующий экран |
|---|---|---|
| Группа персонажей слева | Герои и отряд | `collection` |
| Большая карта на столе | Кампания | `campaign` |
| Доска донесений | Разведоперации | `operations` |
| Стойка оружия справа | Испытания | `challenges` |

Подписи — компактные тёмно-золотые таблички у нижнего края зон, без поверхностных карточек с дублирующими кнопками. Весь соответствующий участок картины — нативная HTML-кнопка с `data-screen`; она поддерживает клавиатуру, фокус и доступное имя. Вся сцена по-прежнему скроллится горизонтально `touch-action:pan-x`; боковая и нижняя навигация сохранены.

Старые DOM ID игрового прогресса оставлены в визуально скрытом тексте каждого hotspot, так что `renderHeadquarters()` по-прежнему получает настоящие данные, не меняя правил игры, валют, сохранений и операций.

## Качество и ограничения

- Картина не разделена на интерактивные 3D-объекты: области клика приблизительно прямоугольные, привязаны к четырём композиционным зонам. Это сознательно лёгкая версия для мобильного Safari.
- Граница областей может требовать художественной подстройки на реальном телефоне. Сложную полигональную карту клика вводить только после оценки.
- Подписи должны находиться **под объектами**, не перекрывать изображённые лица, карту и доску.
- Проверить свайп непосредственно по области карты и персонажей: касание без движения открывает раздел, движение панорамирует.
- Проверить landscape 844×390 и 932×430, notch/safe-area, нижнюю панель, конец панорамы, отсутствие внешнего горизонтального скролла, быстрые переходы и возврат из боя.
- Физический iPhone Safari пока не проверен. Художественное согласование владельцем требуется до merge.

## Границы

В этом PR изменены только разметка главного штаба, его изолированные стили, тесты и данный документ. Не менялись игровые механики, экономика, боевая система, арт-файлы и канон мира.
