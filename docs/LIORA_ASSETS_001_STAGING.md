## Вывод по последовательности
**Сначала разложить два оптимизированных GLB и зарегистрировать пути, потом привязать щит в Babylon.** Связывание — операция на сцене: import щита → поиск кости левой руки → корректный локальный трансформ → родительская привязка → воспроизведение каждого клипа. Не запекать щит в GLB персонажа до проверки посадки и анимаций.
