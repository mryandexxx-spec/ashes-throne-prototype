# LIORA-UNARMED-001 — выпуск Лиоры без щита

**13 ноября 2026 · [В РАЗРАБОТКЕ]**. Решение владельца по результатам личной проверки страницы на iPhone: «отвязывай щит ... будем выпускать Лиору без щита пока что». Задача привязки откладывается для нового специалиста; не считать прошлые варианты крепления принятыми.

## Цель
Показывать Лиору **одну**, не импортируя, не привязывая и не визуализируя отдельную модель щита. Не затрагивать игровые сохранения, бой, ростер и другие модели.

## Изменения
- Новая тестовая страница `liora-lab.html`; исторический URL `liora-shield-lab.html` сохранён для уже открытой пользователем ссылки, но тоже стал страницей Лиоры без щита.
- `liora-shield-lab.js` загружает **только** `LioraModelAssets.url`, создаёт только персонажа и Babylon-сцену; больше не запрашивает `LioraShieldAssets.url`, не создаёт `lioraShieldSocket` и не вызывает `LioraShieldAttachment` или `LioraShieldCombatPose`.
- Убраны слайдеры позиции/поворота щита и специальный переключатель боевой коррекции. Осталось переключение и покадровая проверка **15 анимаций** оригинального GLB. Некоторые клипы исторически содержат `Shield` в названии, но теперь проигрываются **без предмета** и не принимаются как финальная боевая анимация.
- `dev/assets/models/liora-shield-mobile.glb` и исходные JS-модули крепления сохранены **как неактивные исследовательские материалы**, чтобы следующая модель могла продолжить работу; в веб-страницу они не подключаются и в runtime игры не включены.
- Контрактный тест `tests/liora-unarmed-preview.test.js` требует отсутствие подключаемых скриптов, элементов управления и импорта щита. Браузерный тест `tests/liora-shield-babylon-browser.cjs` перепрофилирован на одну модель: ровно один GLB-запрос, один рендер-меш, 15 клипов, 5 фаз каждый, отсутствие корневых скачков, проверка landscape в Chromium и WebKit.
