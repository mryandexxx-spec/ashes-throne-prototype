# Login-001 — календарь входа, семь ежедневных наград

**Дата:** 2026-11-08. **Статус:** [В РАЗРАБОТКЕ], отдельный PR, **не в main**. Основание: согласованный порядок Daily-001 → Login-001 → Abilities-UI-001 из `docs/NEXT_DAILY_LOGIN_ABILITIES_2026-11-08.md`.

## Функция

- Отдельный экран из главного меню, семь видимых последовательных дней.
- После нажатия **«Забрать награду»** выдаёт игровую валюту, Account XP и один из существующих компонентов G.
- Только **одна** награда за локальный календарный день. Фактический вход без нажатия не оплачивается.
- Пропуски не сбрасывают прогресс. После седьмой выплаты цикл повторяется с первой.
- Прошлая системная дата не позволяет повторно получить награду; будущая дата локально не проверяема без доверенного сервера.
- Состояние `login` добавлено как *необязательное* поле `ashes-throne.progress.v3`: совместимость со старыми профилями, проверка повреждённых записей, атомарное сохранение вместе с начисленными ресурсами.
- Не меняются боёвка, награды миссий, цены экипировки, ограничения уровней, Daily-001.

## Приёмка

- На чистом профиле доступна первая награда; повторное получение того же дня блокируется.
- Перезагрузка не сбрасывает отметку, валюту или XP.
- Пропуск 1–N дней сохраняет следующий номер награды.
- После 7-го дня на следующий день доступен новый день 1.
- Повреждённое поле календаря не перезаписывается; при ошибке сохранения начисление возвращается назад.
- iPhone Safari в landscape: прокрутка, седьмой элемент, доступная кнопка, safe-area, отсутствие горизонтального переполнения.
- Проверка CI не равна проверке на устройстве. Слияние — только по отдельному разрешению владельца.
