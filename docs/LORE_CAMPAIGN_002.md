# LC-002 — интерактивная карта лорных кампаний

**14 ноября 2026 · [В РАЗРАБОТКЕ: отдельная ветка, не main]**  
Зависит от **LC-001 / PR #317**, документация и SVG-макеты в **PR #316**, приватный сценарный план в **PR #62**. Все PR требуют отдельного разрешения на слияние. Техническое основание: игровой main `17fd802`, мир `858b195`; перед merge проверить заново.

## Реализованный объём в ветке

1. Существующая карточка **«Кампании лора»** (`#campaignHub`) открывает отдельный экран выбора хроники, затем 2D-карту первого акта «Пяти теней».
2. Маркеры и доступная текстовая альтернатива получаются **из `LoreCampaignData`**, не дублируются вручную; связи событий SVG, без географических утверждений или прямого моста через ущелье.
3. Клик по точке обновляет карточку и статус (доступно/закрыто/пройдено), показывает причину недоступности. Имена ещё закрытых узлов скрыты для предотвращения преждевременных спойлеров.
4. Поддержаны возврат `Escape`, своя кнопка «К историям», внешняя кнопка `#campaignBackButton` (карта → обложки → три кампании → штаб). Обработчик делегирован, повторное открытие не множит слушатели.
5. Повторно использовано принятое изображение `assets/campaign-cover-five-shadows.webp`; новые тяжёлые ассеты, WebGL и npm runtime-зависимости не нужны. Стиль согласован с `docs/UI_DESIGN_SYSTEM.md`.
6. Для `844×390` и `932×430` добавлена компактная landscape-компоновка. Маркеры от 44×44 CSS px, `aria-pressed`, `focus-visible`, `role=group`, текстовые статусы, `prefers-reduced-motion`.

## Строгие ограничения

- **Игровые сцены, задания, выборы, журнал и сохранение прогресса — LC-003/004, здесь НЕ реализованы.** Для первого узла статус «Доступно» значит доступность **по зависимостям**, но не обещает запуска: кнопка сцены отключена с явным сообщением. Узлы 2–3 пока заблокированы; это ожидаемо.
- `LoreCampaignCore.fresh()` — только память сеанса. `ashes-throne.lore-campaign.v1` не записывается; перезапуск возвращает к началу. Не притворяться завершённым сохранением.
- Ни получение наград, ни энергия, ни ручной/автоматический бой, ни симуляции, ни мгновенное получение не подключаются.
- Сохранены `MissionData`, `CampaignCore`, `ProgressCore`, `CombatCore`, `StoryDemoCore` и старый сценарный sandbox, не переписываются.
- Сцены, анимации и дополнительные культурные/географические факты не создавались; литературный канон не менялся.
- Ветка **не опубликована**, нельзя называть версию видимой на GitHub Pages до согласованного merge и проверки публикации.
