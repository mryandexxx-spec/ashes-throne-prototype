# LC-005 · Обязательные победы в лорной кампании

**14 ноября 2026 · [В РАЗРАБОТКЕ: код в Draft PR #323].**  
**Решение владельца [УТВЕРЖДЕНО]:** «Я хочу чтобы сражения были обязательной частью прохождения». Это заменяет прежний принцип «обязательны только диалоги/осмотр, боевые испытания факультативны» именно для игрового прохождения «Пяти теней».

## Рабочая система

Пилот: **FS-01 → победа в бою → FS-02 → победа в бою → FS-03**. Поражение, отмена и недоступный сейв не открывают следующий эпизод. Каждый рубеж ставится только у конкретного узла через `node.requiredBattleId`, **по умолчанию поле отсутствует**. Публичная поставка сохраняет `contentId:null` и **не публикует** приватные сцены или недоговорённые сюжетные сражения.

- `LoreCampaignData.catalogIsValid` проверяет уникальность `requiredBattleId`, допустимость и отсутствие поля у финального узла.
- `LoreCampaignCore.available()` проверяет не только `completedNodeIds`, но и `battleClearedNodeIds` у каждого обязательного предшественника. `fresh()` добавляет пустой массив побед.
- `LoreCampaignSceneSave.validate` допускает старые v1-сохранения без поля (нормализация в пустой массив). Запрещает неизвестные, дублированные, преждевременные боевые квитанции и несуществующие узлы. Боевой результат записывается **в тот же лорный ключ**, без изменения обычных ресурсов.
- `LoreCampaignSceneRuntime.beginRequiredBattle` начинает **одну** попытку только после завершённого сюжета и до первой победы. `recordBattleVictory` требует активную попытку и точный ID. Пишет победу атомарно с проверкой чтения. `cancelRequiredBattle` снимает попытку.
- UI показывает причину блокировки следующего узла и явную кнопку «⚔ Обязательный бой» в результате и карточке пройденного узла. Дополнительная тренировка скрывается, когда история использует обязательные рубежи.
- `game.js` повторно использует **существующий CombatCore, Babylon.js, подготовку отряда и анимации**, но в изолированном режиме `loreRequired`. Выигрыш фиксируется **после** окончания настоящей схватки. Отдельный экран победы/поражения/ошибки сохранения. Отступление возвращает к карте без записи.

**Не происходит:** создания новой формулы урона, модификации `progress.v3`, траты энергии, дропа, осколков, наград, отметки очередного диалога без осмотра, появления NPC/фракций в литературном каноне. Боевые противники пока тестовые экземпляры уже существующих шаблонов.
