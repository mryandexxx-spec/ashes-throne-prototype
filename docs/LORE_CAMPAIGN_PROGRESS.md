## Активный пакет B — критерии

1. Сверить принятые части 5–7, речевые паспорта, игровые FS-01…FS-06 и условия открытия.
2. Проектирование — **[ПРЕДЛОЖЕНИЕ]** до сюжетной/авторской приёмки: по три осмысленных игровых действия/последствия на основе литературных событий, не «нажми далее».
3. Новый граф FS-07…09 без нарушения существующих node ID, слоя карты и `ashes-throne.lore-campaign.v1`.
4. Проверка продолжения с FS-06, истории отказов сохранения, возврата из сцены, повторного прохождения и неповреждения прежних решений.
5. Не создавать боёв, магии и экономики, не основанных на утверждённых правилах. Потребность в новом обязательном сражении в пакете B — предмет отдельного дизайна, **не автоматическое разрешение выдумать литературный конфликт**.
6. Node + Chromium/WebKit → игровой PR → отдельное разрешение на merge. Физический iPhone временно отложен.

**Контроль утверждённых решений:** обязательные сражения предусмотрены при прохождении лорной кампании, Рен и Нада обязательны в сюжетных боях согласно правилам подготовки; остальные места под выбранных героев. Новые литературные события и диалоги не утверждаются фактом принятия дорожной карты.
