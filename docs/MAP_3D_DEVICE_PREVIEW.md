## Design critique
Separate static page rather than edit existing campaign or overwrite existing site deployment. Live quality toggle avoids resets and enables comparison on same position; baseline default full CSS-pixel render and shadows on; 67% diagnostic scale and no-shadows optional, not final quality. Use existing touch, Recast, camera, clips and lifecycle. FPS counter is count of rendered frames per elapsed visible interval, not GPU profiler; resolution displayed, reset sample when switching/hidden; don't claim 30/60 device FPS before user measures. Pause loop when hidden; release resources on non-bfcache pagehide. Controls safe-area, landscape, visible attribution and return. Test both browsers in three viewports: real touches before/after toggles, arrivals, FPS label, no overflow, 2 resets and close, credits. Verify production file scope, exact binary manifests, CI and actual public URL before claim.
