# NADA3D001 — игровая интеграция Нады с dev-структурой Дюны

**Статус: [В РАЗРАБОТКЕ]**. Прежде чем сливать PR, обязательно загрузить и проверить игровой GLB. Художественная концепция v2 утверждена; точный результат 3D в браузере пока не принимался.

## Проверенный прототип структуры Dune GoH

Сверены `mryandexxx-spec/Dgoh-game/main`: `dev/README.md`, `dev/ARCHITECTURE.md` §5, `dev/assets/models/manifest.json`, `dev/assets/models/README_UPLOAD.md`, `dev/models/README.md`, `dev/src/assets/models.js`.

В Дюне исходники расположены в `dev/assets-src/`, игровые модели — в `dev/assets/models/`, карта URL — в `dev/src/assets/`. Там имеется свой `dev/tools/build.mjs`, компилятор и манифест кэша PWA. В «Пепельном престоле» сейчас классический статический Babylon-прототип на GitHub Pages, без такой сборки. **Здесь переносим только разделение каталогов и контрольный манифест**, без изменения всей архитектуры.

## Анимации и визуальный контракт

- `Idle_11` → idle, guard; `Archery_Shot_3` → basic/special/powerful; `Hit_Reaction_1` → hit/ward; `Electrocuted_Fall` → смерть.
- `Running` и `Walking` сохранены для будущей постановки движения. `mage_soell_cast` не назначен: Нада не маг и её третий навык — выстрел.
- Источник сохраняет 16 673 вершины, 17 381 треугольник, 66 костей, 8 анимаций, один JPEG baseColor 2048². Никакой новой анимации генерацией кода не создаётся.
- `nada-glb-runtime.js` использует **тот же Babylon Engine и кадр боя**, что Рен. Загружает GLB только если Нада участвует, удерживает модель на якоре текущего бойца и блокирует дублирующий horizontal root motion.
- В карточке включается существующий поворотный WebGL viewer (на одном canvas). Для Рена не меняются файл, специальные позы и параметры его оригинального клипа.
- Если файл недоступен или GLTF loader падает, карточка возвращается к утверждённому портрету Нады, а на арене остаётся простая модель бойца; бой, награды, сохранения и выбор целей продолжаются без 3D.
- Модель визуально может требовать ориентировки, изменения масштаба и проверки кривых анимации — это **не подтверждено в реальном WebGL**.
