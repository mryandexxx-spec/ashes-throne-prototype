# NADAOPT001 — облегчение 3D-модели Нады

**Дата:** 13 ноября 2026  
**Версия-кандидат:** `v0.3.135 · NADAOPT001`  
**Статус:** [В РАЗРАБОТКЕ] — код и автотесты готовы; ждёт CI (включая WebKit), разрешения на слияние и проверки на iPhone.

## Задача

Облегчить `dev/assets/models/nada-mobile-animated.glb` (3 096 808 байт) по образцу RENOPT001 ([REN_GLB_OPTIMIZE_001.md](REN_GLB_OPTIMIZE_001.md)).

## Что было внутри

У Нады нет карт нормалей и металличности/шероховатости. Только одна цветовая текстура.

| Часть | До | После (вариант B) |
|---|---|---|
| Цвет 2048, JPEG | 1,41 МБ | WebP 2048 q90 ≈ 0,5 МБ |
| Сетка (17 381 треугольник), float32 | ≈0,97 МБ | `KHR_mesh_quantization` |
| 8 анимаций, 29 815 ключей | ≈0,47 МБ | прореживание (`resample`) → 14 998 ключей |
| **Итого** | **3 096 808 байт** | **1 462 284 байта (−53%)** |

Риг (66 костей), сетка и все 8 клипов сохранены. Внешние декодеры (Draco/meshopt) не нужны.

## Варианты (сравнение 13.11.2026)

Геометрия и анимации у всех вариантов одинаковые, различается только текстура. PSNR считался по кадрам рендера (лицо крупно и в полный рост, Idle_11, кадр 0) относительно оригинала.

| | Текстура | Размер | PSNR лицо / тело |
|---|---|---|---|
| A | JPEG без изменений | 2,40 МБ | 52,0 / 52,4 дБ |
| **B** | **WebP 2048 q90** | **1,46 МБ** | **47,4 / 49,0 дБ** |
| C | WebP 2048 q80 | 1,27 МБ | 45,6 / 47,2 дБ |
| D | WebP 1536 q90 | 1,31 МБ | 46,5 / 47,9 дБ |
| E | WebP 1024 q90 | 1,17 МБ | 44,5 / 46,1 дБ |

Кадры: `docs/evidence/nadaopt001/`. Генератор вариантов: `tools/nadaopt001-variants.mjs` (одноразовый).

Максимальное отклонение анимаций после прореживания — 3·10⁻³ (Archery_Shot_3; для кватернионов это меньше 0,5°).

## Решение владельца

[УТВЕРЖДЕНО 13.11.2026] Вариант B. Те же настройки цвета, что у Рена. Файл получен без правок скриптом `tools/optimize-hero-glb.mjs`: правила для нормалей и MR у Нады ни на что не срабатывают. Результат детерминирован: два прогона дают побайтно одинаковый файл.
