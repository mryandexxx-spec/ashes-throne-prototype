**Статус бинарного ассета:** [РЕАЛИЗОВАНО] в рабочей ветке, если GitHub blob и дерево подтверждены; не означает внедрение портрета в экран.

## Художественный эталон

Утверждённый вариант — **«Нада в туманных руинах»**, портрет бюстового ракурса без декоративной карточной рамки. Это **не** более ранние портреты Нады с тёмным студийным фоном, которые владелец отклонил по несовпадению с Реном.

- Живописная полу-реалистичная стилизация с видимыми мазками, без фотографической детализации кожи.
- Палитра природного серо-каменного и приглушённого бордового; мягкий рассеянный дневной свет.
- За плечами туманные скальные сооружения Садов над пропастью; изображение *не определяет* точную географию.
- Тёмные волосы, длинная коса, выразительный внимательный взгляд, дорожная одежда с бордовым верхом, бумажные свёртки и небольшой арбалет за плечом.
- Крупная фигура и лицо хорошо различимы в маленькой игровой рамке; по настроению и композиции согласованы с портретом Рена.
- Никаких новых литературных биографических сведений об арбалете и умении сражаться.

## Интеграция

Текущая игра использует `assets/ren-portrait-ui.webp` в экранах Рена; перенос Нады в постоянный ростер и замена её визуального плейсхолдера — **отдельная игровая задача**, не входящая в этот PR. В этом этапе не менять `game.js`, баланс, сохранения, HTML, CSS и версию игры. Сначала безопасно сохранить ассет.

## Проверки и ограничения

1. Сверить SHA-256 WebP и подтвердить в GitHub точный путь `assets/nada-portrait-ui.webp`.
2. Проверить, что WebP декодируется как 256 × 256, корректно кадрирован, не содержит текст/рамку.
3. Изображение должно быть визуально согласовано с одобренным PNG.
4. Бинарный WebP добавлен Git-объектом; после записи дерева необходимо подтвердить GitHub-путь и контрольную сумму.
5. Отдельно перед интеграцией в UI протестировать реальные экраны, iPhone Safari и загрузку из GitHub Pages.
