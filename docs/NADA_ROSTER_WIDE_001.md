# NADAROSTER001 — исправление обрезки портрета Нады в коллекции

**Статус:** [В РАЗРАБОТКЕ] до проверок PR и приёмки на устройстве. **Дата:** 12.11.2026.

## Причина

На предоставленном владельцем скриншоте `IMG_6489.png` верхняя часть портрета Нады в широкой рамке коллекции была обрезана. Использовался **квадратный 256×256** портрет, но слот в сетке горизонтальный. Правило `object-fit:cover` кадрировало лицо сверху, костюм снизу.

## Минимальное исправление

- Добавлен **отдельный широкий 2:1 WebP** `assets/nada-portrait-roster.webp` с композицией, учитывающей рамку, и видимой причёской, лицом, сумкой, арбалетом. Изначально изображение создано как горизонтальная версия согласованного художественного образа v2 в этой беседе.
- Игровой ассет: **384×192**, `6188` байт, WebP quality 65; SHA-256 `1328590c2eec5113e4162a9615be6fb988a92fdb16781402d1da826f92f494c4`.
- Только `renderHeroes()` в `game.js` использует широкий файл `?v=1`, с корректными `width`/`height`. В досье и карточке остаётся прежний **квадратный** `nada-portrait-ui.webp?v=2`.
- Контейнер и рамка, декоративные оверлеи и размеры сетки сохраняются. В конце `styles.css` сузили правило ровно до `#collection .hero-avatar-nada .nada-collection-portrait`: img закреплён по всей ширине и высоте, `object-fit:cover`, `object-position:center 42%`. Для широкой картинки ожидается минимальная обрезка по краям, а не по лицу.
- Ни Рен, ни CSS иных героев, ни боевые данные, прогресс, сохранения, 3D-модели и баланс не менялись.
- Версия `0.3.127 · NADAROSTER001`; ссылки в `index.html` обновлены для обновления CSS/JS в Safari.

## Проверки

- Тест `tests/nada-roster-wide-001.test.js`: строгие размеры/хеш изображения, раздельные ссылки на широкий и квадратный исходники, стили, версия.
- Существующие `tests/nada-portrait-002.test.js`, `tests/nada-roster-preview.test.js`: обновлены ожидания для двух квадратных и одного широкого использования.
- CI GitHub Actions и browser smoke должны показать отсутствие регрессий; физический iPhone Safari ещё не проверен.

## Мобильный чек-лист

1. В футере должна появиться версия `v0.3.127 · ... + NADAROSTER001`. При несовпадении проверить Pages и кэш Safari.
2. Открыть коллекцию в альбомной ориентации, найти Наду: всё лицо и верх головы в пределах рамки, без пустых полос и растяжения.
3. Проверить карточку и досье Нады: квадратный v2 остался прежним.
4. Рен и другие карточки не изменились; в коллекции нет горизонтального скролла.
5. Проверить переходы ростер → карточка → назад и бой → повтор, без зависаний и сброса прогресса.
