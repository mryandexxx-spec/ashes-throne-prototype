# NET-005 — приказы сети, освоение/симуляция, переход из Finder

**Статус: [В РАЗРАБОТКЕ] / [ПРЕДЛОЖЕНИЕ].** Ветка `feat/net-005-network-orders-simulation-finder` поверх NET-004 PR #389; более ранние зависимости: NET-003 #388 → NET-002 #387 → NET-001 #386. Ни один этап не слит в `main`.

## Подтверждённый объём

- **NET-004 [УТВЕРЖДЕНО]:** два отдельных столкновения и полное восстановление героев между ними. NET-005 не меняет это правило и не редактирует боевое ядро.
- **NET-005 [ПРЕДЛОЖЕНИЕ до приёмки]:** только прототип за `?networkPilot=1`, с изолированным `ashes-throne.network.pilot.v1`. Промышленный каталог `NetworkData.CATALOG.templates` пуст. Нет настоящих зацепок, тарифов, начислений материалов/осколков, нового канона и расхода энергии.
- **Порядок направленного поиска:** уже существующая чистая функция `NetworkCore.setOrder` сохраняет целевой тип/регион/материал/героя и счётчик пропусков, `accrue` гарантирует совпадение после K реально поступивших зацепок. NET-005 выводит **только доступные в пилотном каталоге цели**, не подставляет материалы или героев без шаблонов. Приказ действует **на будущие донесения** и не перераспределяет заполненную доску. Сохранение через общий `ProgressWriterCore.exclusive`, проверку владельца Web Lock и readback.
- **Освоение:** `NetworkCore.isMastered` требует сохранённую ручную оценку не ниже `config.masteryScore` **для той же пары «шаблон|уровень»**. Новая чистая `NetworkCore.simulate` отклоняет отсутствие освоения, активный бой, уже снятую зацепку, закрытый регион или несовпадающую версию/поля источника. Если разрешена — удаляет одну зацепку с доски, выдаёт следующий serial со статусом `done`, `kind=simulated`, `score=0`; увеличивает обычный счётчик завершённых операций, **не** меняет лучшее ручное освоение и `threatIntel`. Никаких выплат, чтения кошелька или 3D.
- `NetworkRewardCore.prove` распознаёт прошедшие проверку записи `manual` и `simulated` в **одном** serial-порядке. Однако сам `NetworkRewardCore.claim` в игровом UI не вызывается; реальные источники и суммы отсутствуют. До утверждения NET-006 практической выплаты нет.
- **Почему «Симулировать» заблокировано в обычном пилоте:** в NET-004 результат пробного боя — техническая заглушка `score=0`, а тестовый порог освоения равен 3. Мы **не повышаем** баллы задним числом и не выдаём бесплатное освоение; корректность симуляции и повторного запуска проверяется на изолированном тестовом профиле с доказанным ручным результатом. Эти числа **не утверждённый баланс**.
- **Finder:** `GearSourceData.findNetworkSources` — только чтение реально соответствующих `materialId` шаблонов из разрешённого каталога. Нельзя называть пробный шаблон источником материала, поскольку все его `materialId=null`. Поэтому Finder честно сообщает «Разведсеть пока не подтверждена как источник этого материала»; при URL-флаге предлагает отдельную кнопку **«Посмотреть пробную разведсеть»** без обещания награды. Возврат восстанавливает экран карточки героя и прежний раздел поиска, не сохраняет / не меняет ни экипировку, ни постоянный отряд.

## Реализация

- `network-core.js` — новая чистая симуляция, строгая запись `kind=simulated`.
- `network-pilot-session.js`, `network-pilot-ui.js`, `network-pilot.css` — сохранение приказов, фильтр целей, блокировка симуляции, действия/подписи и адаптивная панель.
- `gear-source-data.js`, `gear-ux-004.js`, `game.js` — одностороннее получение подтверждённых ссылок и обратимый опциональный переход из Finder без изменения нормальной кампании.
- `network-reward-core.js` — доказательство serial-истории с типом `simulated`.
- `index.html`, `package.json` — версия `0.3.189 · NET005PILOT`; только URL-флаг открывает сеть.
- `tests/network-005-orders-simulation.test.js`, `tests/network-005-browser.cjs` и `.github/workflows/network-005-tests.yml` — логика, сохранение, два браузера (844×390 и 932×430), сценарий Finder→сеть→Finder, все исходные NET-004 браузерные проверки.

## Границы и риски

Числа и реальные награды, способ пересчёта модификаторов и сведений об угрозе, порог освоения, наполнение каталогов, экономическая модель — **NET-006** с отдельным решением владельца. Finder не должен предлагать наведение на конкретный материал, пока нет совпадающего утверждённого шаблона. При повреждении пилотного сохранения никакого автоматического сброса или повторной выплаты.

Проверки GitHub Actions и конкретный успешный SHA фиксируются в PR **после** окончания прогонов; предыдущие зелёные тесты NET-004 не доказывают работу NET-005. Физический iPhone Safari не тестировался. Слияние с `main` — только по отдельному разрешению.
