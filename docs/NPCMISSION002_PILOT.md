# NPCMISSION002 — ранняя пара лекарь/пращник в demo-mission-2

**[В РАЗРАБОТКЕ] / v0.3.165 · NPCMISSION002 / 15.11.2026.**

## Цель
Проверить первый реальный набор NPC **не в лорных битвах**, не заменяя опубликованное содержимое по умолчанию. Основа: [слитый PR #340](https://github.com/mryandexxx-spec/ashes-throne-prototype/pull/340) и экспериментальный каталог `npc-enemy-data.js`. В планах NPC-ENEMY-001 эта стадия называется «PR B — одна пилотная миссия». Утверждённые параметры наград/условий звёзд **не изменены**.

## Важные ограничения

- **По умолчанию `demo-mission-2` остаётся прежней миссией с пятью тестовыми врагами.** Пробная замена активна **только** при URL query `?npcMissionPilot=1`; обычные `ves`, `shade` и другие ID остаются в своих источниках.
- Новое столкновение использует **два человеческих архетипа Садов**: `npc-ridge-slinger` (скорость, точечный урон) и `npc-field-medic` (восстановление 36 HP одного бойца, 20 HP группы на первом уровне), **оба L1 / 1★ / G1 / уровень 1**. Для **этой единственной пробной миссии** зафиксированы облегчённые HP/Protection: пращник **75/5** (каталог 88/14), лекарь **55/5** (каталог 103/24). Они явно указаны в `NpcMissionPilot` и показаны игроку через реальный HUD. Это не бафф/нерф каталогов NPC и не адаптация под текущую мощь игрока. Это учебная гипотеза, не историческое столкновение Рена и друзей. Новые виды сархи/лауны не помещены в географию Садов без лорной причины.
- В отличие от обычной кампании **пилот совершенно не меняет профиль игрока**: не списывает энергию, не выдаёт ресурсы, не открывает миссии, не начисляет ежедневные задания и не пишет рейтинг звёзд. На экране результата выдаётся **тестовая оценка** по текущим правилам `MissionData.score` (1★ победа, 2★ все союзники живы, 3★ не более 9 действий). Игрок возвращается к кампании без последствия.
- `npc-mission-pilot.js` — отдельный неизменяемый манифест миссии с уникальными экземплярами; не переписывает `MissionData`, `CampaignData`, прогрессию и боевые формулы. Не добавляет NPC в `HEROES` и `SaveCore`.
- `COMBAT_VISUALS` добавляет **две тестовые низкополигональные капсулы** только когда в URL есть `npcMissionPilot=1`; по умолчанию нет дополнительных Mesh/Texture/GLB. Это не окончательный визуальный облик пращника и лекаря.
- Новые способности NPC выполняет существующий `CombatCore`, с выбором живых союзников на лечение `EnemyDecision`.

## Контрольные сценарии

Для 5 реальных игровых героев Садов `ren, nada, liora, art, sava` использовать актуальные `HeroStatsProfiles` и `HeroStatsCombatBridge`, без выдуманных дополнительных ресурсов. Проверить комбинации: все пятеро L1 и L3, тройка Ren/Nada/Sava L3, тройка Ren/Liora/Art L3, четвёрка Ren/Nada/Liora/Art L8 (при соблюдении допуска аккаунта к соответствующему уровню). В каждой — сиды 1, 17, 71 и три стратегии: сначала лекарь, сначала пращник, штатный автобой. Всего 45 прогонов на `CombatCore` с включёнными проверками попадания/крита/статусов/пробивания, порогом 150 действий.

Для каждого зафиксировать: долю побед, лучший рейтинг, среднее число действий игрока, ранения/лечение и состав. **Важное условие:** не утверждать достигнутые 3★ или баланс по одному тесту. При неприемлемых результатах переработать тестовый манифест, но не глобальные характеристики всех NPC ради одной миссии. Соблюдать контракты лечения, cooldown, запрета воскрешения и отсутствие дополнительных ходов.

## Измеренный баланс на текущем `CombatCore` — [ТЕСТОВАЯ ГИПОТЕЗА]

Проверены **45 из 45 завершённых боёв** с реальными четырнадцатью характеристиками героев из `HeroStatsProfiles`, при `rngSeed` 1, 17 и 71, всех flags `hitChecks/critChecks/penetrationChecks/statusChecks` и трёх последовательных стратегиях. Эти тесты были также выполнены вне GitHub CI непосредственно на исходниках новой ветки; для заявления о прохождении CI нужно дождаться финального head.

| Состав / уровень (1★, без экипировки) | Побед | Три звезды | Среднее действий игрока |
|---|---:|---:|---:|
| Рен, Нада, Лиора, Арт, Сава · L1 | 9/9 | **6/9** | 8.0 |
| Та же пятёрка · L3 | 9/9 | **6/9** | 8.0 |
| Рен, Нада, Сава · L3 | 9/9 | **9/9** | 7.4 |
| Рен, Лиора, Арт · L3 | 9/9 | **9/9** | 8.1 |
| Рен, Нада, Лиора, Арт · L8 | 9/9 | **9/9** | 7.1 |
| **Итого** | **45/45** | **39/45** | — |

**Сравнение тактик на L1 полной пятёрки:** фокус по лекарю — **9/6/6** действий (3★ в каждом из трёх сидов); фокус по пращнику — **10/10/10** действий (только 2★); штатный автобой — **9/6/6** действий. **Это доказывает, что выбор цели влияет на оценку в данной сетке, но не доказывает финальный баланс.** Старый состав с полными базовыми статами NPC проходился во всех 45 тестах, однако не дал **ни одной 3★** и требовал 10–14 действий.

**Открытая проблема дизайна:** три героя в испытанных сочетаниях иногда получают лучшую оценку, чем полная пятёрка; оценка считает все действия союзников, включая слабые поддержки. Не менять правила начисления звёзд ради одного теста; исследовать это отдельно при боевой стандартизации кампании. Отдельно провести реальные пользовательские браузерные прогоны, включая HUD, ручной выбор и повтор. Эти 45 симуляций не являются доказательством корректности 3D, сохранений или iPhone Safari.

## Регрессионные проверки

1. Обычная `demo-mission-2` остаётся прежней, задания/сейвы не мигрируются; `black-pass-ambush`, `demo-mission-3`, T/N, OPS, FS-01…06 не изменены.
2. `?npcMissionPilot=1`: экран подготовки → бой → выбор целей, лечение, победа/поражение → тестовая оценка → повтор → возврат, **без изменения энерго-кошелька и `campaignProgress`**.

4. `npm test` и все доступные браузерные GitHub Actions должны завершиться успешно. В CI нельзя подменять фактическое тестирование iPhone.
