# REN-COMBAT-C — «Чувство тропы» и пробная модель сопротивления

**8 ноября 2026 • [В РАЗРАБОТКЕ] • не утверждённый баланс**. Источник состава механик: [REN-001](REN_001_HERO_DESIGN_TAG_BIO_AND_SKILLS.md), предыдущая реализация замедления: [REN-COMBAT-B](REN_COMBAT_B_LEVEL4_SLOW.md).

## Граница утверждённого
**[УТВЕРЖДЕНО]** Три направления пассивки Рена: добавочный урон Рена по уже ослабленной цели, бонус эффективности наложения на противников **без пониженного сопротивления**, командный бонус союзникам с тегом `gardens-over-abyss`. Замедление «Точного удара» начинается на уровне способности 4.

**[ПРЕДЛОЖЕНИЕ — тестовые числа из REN-001]:** +15% урона по цели с уже активным негативным эффектом, +10 процентных пунктов при проверке наложения, +5% прямого урона живым союзникам Садов (включая самого Рена). +15 и +5 складываются до +20% **до единственного округления**; не умножаются последовательно. Это не принятое владельцем числовое равновесие.

## Технический контракт
- `AbilityData`: пассивка `Чувство тропы · проба` задаётся `combatRules`; никакой проверки `trial-ren` в `CombatCore`. Не назначать правило Наде и Лиоре без утверждения их происхождения.
- `CombatCore`: вычисляет `bonusVsDebuffedPercent` только для *самого владельца* пассивки, если на цели негативный статус существовал **до текущего попадания**; `guard` не является негативным эффектом. Прямой урон на ходу, где Рен только наложил замедление, не повышается ретроспективно.
- `tagDamagePercent`: всем союзникам с нужным тегом, пока **источник жив**. Включает самого источника, но не зависит от позиции лидера. Повтор источника не складывается внутри вычисления (боевой ростер требует уникальных ID).
- `statusPotencyWithoutResistanceDown`: добавляется только при включённой тестовой проверке `statusChecks:true` на атаке с негативным эффектом **и только при отсутствии** `debuff-resistance-down`. Когда эффект снижения сопротивления есть, он сам уменьшает расчётное сопротивление, но условный +10 не добавляется.
- При `statusChecks:true` пробный `onHitStatus:slowed` потребляет по одному детерминированному RNG-решению на цель, **после успешного попадания**. Прежде чем тратить действие, проверяются корректные `debuffPotency` и `debuffResistance` и резерв RNG; отсутствие полей блокирует команду. Режим `statusChecks` по умолчанию выключен и **не активируется** в сюжетной пробе самостоятельно. Старые legacy-способности с `weakening` сохраняют прежний контракт.
- Проверочная формула вероятности наследует Stats-001E2: `clamp(100 + potency + passiveBonus − effectiveResistance, 5, 100)`. Это **экспериментальная**, не утверждённая формула и не образец окончательной точности статусов. При 0 сопротивления она может давать 100%; баланс и пределы предстоит согласовать.
- Повышение урона и статусная проверка — отдельные этапы команды; успешный удар с отбитым статусом всё равно наносит урон. При смерти цели статус не накладывается. Временно `debuff-resistance-down` может задаваться только техническими тестами, **боевой мощной способности Рена ещё нет**.

## Риски и проверки
**Автотесты:** первый и повторный удар, состояние цели перед ударом, отсутствие стеков от нескольких дебаффов, теговый бонус другому союзнику, смерть источника, отсутствие бонуса без тега, сопротивление без и с `debuff-resistance-down`, RNG-расход и отказ на ошибочном профиле, пробный typed-weaken, повторяемость seeded-сценариев, неизменность v3-сохранений и общего состава постоянной коллекции.

**Риски:** (1) +20% и сохранение двухходового замедления могут быть сильнее желаемого; (2) legacy-боевой режим без statusChecks гарантирует наложение при попадании, поэтому бонус эффективности наложения в обычной сюжетной пробе скрыт; (3) техническая формула сопротивления может достигать 100% и должна быть пересмотрена до утверждения боевого баланса; (4) реальные Safari, auto-mode и многоступенчатые волны требуют приёмки, даже если CI зелёный.

## Вне среза
- Вариант мощного умения «Сорвать построение», массовое понижение сопротивления и числовые параметры мощного удара **не утверждены** и **не подключены**.
- Нет постоянного Рена, предметов G4–G13, новых покупок, сохранения `skillLevels` для сюжетной пробы, изменений литературного канона.
- Полное утверждение чисел пассивки и сопротивления — отдельный авторский выбор после тестовой реализации.
