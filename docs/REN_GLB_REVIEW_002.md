# REN-GLB-REVIEW-002 — просмотр пользовательского GLB Рена

**Статус:** [ПРЕДЛОЖЕНИЕ], отдельный визуальный эксперимент; не утверждение внешности героя и не замена игровой модели.

## Файл-основание

Пользователь повторно загрузил `tmp7nd78atb 2.glb`. Проверены заголовок GLB 2.0, точное совпадение длины (671324 байта), 1 меш, атрибуты POSITION/COLOR_0; отсутствуют текстуры, скелет и анимации. Это локальное вложение беседы — **сам бинарный файл не сохранён в GitHub**.

## Как открыть на телефоне

После согласованного merge и публикации GitHub Pages перейти на `/ren-glb-review.html`, нажать «Выбрать GLB», найти скачанный исходный файл в приложении «Файлы», затем поворачивать фигурку пальцем. Кнопки позволяют сравнить её с уже существующим процедурным макетом. Файл обрабатывается локально средствами Babylon.js; серверной загрузки нет.

## Границы и проверка

- Боевой `game.js`, `ren-visual-model.js`, сохранения, характеристики и художественный канон не меняются.
- Страница использует тот же Babylon.js CDN, плюс официальный модуль loaders.
- Статические Node-тесты входят в общий набор. Отрисовку в Chromium, экспорт, реальные жесты и Safari проверять отдельно; CI Node не доказывает успешный импорт в физическом браузере.
- Для хранения **именно этого** GLB в репозитории потребуется отдельный разрешённый канал загрузки бинарного файла. Пока это локальный просмотр и сравнение, а не постоянный игровой ассет.
