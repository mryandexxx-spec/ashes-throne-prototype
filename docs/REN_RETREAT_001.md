# RENRETREAT001 — Рен возвращается бегом

**Дата:** 13 ноября 2026  
**Версия-кандидат:** `v0.3.139 · RENRETREAT001`  
**Статус:** [В РАЗРАБОТКЕ] — PR открыт, ждёт CI, разрешения на слияние и оценки владельцем в игре.

## Проблема

Владелец: «момент, когда Рен идёт к врагу и возвращается обратно, слишком затянут». После удара Рен возвращался шагом спиной вперёд со скоростью клипа Walking (≈1,7 м/с). На арене ARENA-ENGINE-003 до врага 7–9 м, поэтому возвращение занимало 4–5 с из 7–8 с всей атаки.

## Решение

[УТВЕРЖДЕНО 13.11.2026] Вариант 1 из трёх предложенных: после удара Рен разворачивается (0,22 с), бежит к своему месту клипом Running с той же скоростью, что и к врагу, и поворачивается лицом к противнику (0,22 с).

| Фаза (×1) | Цель в 7,4 м: было → стало | Цель в 9,1 м: было → стало |
|---|---|---|
| Бег к врагу | 1,22 с → 1,22 с | 1,50 с → 1,50 с |
| Торможение и удар | 1,12 с → 1,12 с | 1,12 с → 1,12 с |
| Пауза / разворот | 0,20 с → 0,22 с | 0,20 с → 0,22 с |
| Возвращение | 4,08 с → 1,29 с | 5,06 с → 1,57 с |
| Установка / поворот к врагу | 0,14 с → 0,22 с | 0,14 с → 0,22 с |
| **Итого** | **6,8 с → 4,1 с** | **8,0 с → 4,6 с** |

Подход к врагу, удар и момент контакта не менялись. Цикл бега привязан к пройденному расстоянию, поэтому ноги не скользят. Если цель уже в зоне удара (перемещения нет), остаётся прежнее короткое восстановление без разворотов.

## Что посмотреть владельцу

1. Разворот после удара и поворот к врагу в конце: не слишком ли резкие (по 0,22 с).
2. Темп всей атаки при ×1; при ×2 и ×4 она ускоряется вместе с боем.
3. Если подход к врагу тоже кажется долгим — есть вариант 3 (ускорить бег в обе стороны в 1,25 раза).
