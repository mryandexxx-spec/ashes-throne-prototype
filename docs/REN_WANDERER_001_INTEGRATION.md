# REN-WANDERER-001 — интеграция предоставленной модели Странника

**Статус: [В РАЗРАБОТКЕ].** Заменять опубликованного Рена и объявлять мобильную приёмку до загрузки ассета и проверки сцены нельзя.

## Источник и проверенные параметры
Входной архив владельца: `wanderer_blender_v1.zip`, внутри `people_output/wanderer/wanderer.glb`, `.blend`, рендеры и исходники MakeHuman. Согласно `validation.json` и самостоятельному просмотру GLB JSON: 6 361 580 байт, 477 meshes, ~183 818 треугольников, один skin с 18 костями, **0 animation groups**, 0 texture objects. Процедурные материалы частично остаются только в Blender: экспорт не содержит запечённых текстур.

Файл ассета **не включён в этот PR**, потому что канал GitHub connector не поддерживает передачу загруженного в чат бинарного GLB из изолированной среды. Файл необходимо добавить по пути `assets/ren-wanderer-v1.glb` в ту же ветку **до приёмки и слияния**. Готовый пакет с файлом передаётся владельцу отдельно. Ключевой риск — высокая нагрузка для iPhone Safari (477 мешей).

## Что меняется
- `ren-glb-runtime.js`: загрузка `ren-wanderer-v1.glb`; статичный skin без клипов допустим; модель нормализуется по реальным границам и привязывается к существующему combat visual anchor. Если файл не загрузился, прежняя процедурная модель остаётся видимой. Сценарии боя и состояние не меняются.
- `ren-card-3d.js`: тот же файл в вращаемой карточке, корректное уведомление об отсутствии анимаций.
- Тесты загрузки модели без animation groups, сохранения `fighterId`, отката при ошибке.

## Ограничения и план
1. Загрузить бинарный GLB в ветку и проверить точный путь.
2. Запустить Node CI и Chromium WebGL smoke, удостовериться, что **новый** файл действительно виден и выбирается в бою и карточке; проверить повторный старт/закрытие карточки.
3. Отдельно оценить draw calls, загрузку, FPS и память на iPhone Safari. Нужны оптимизация 477 мешей, LOD/объединение, запекание PBR карт.
4. Отдельный этап: анимировать скелет с корректными skin weights. До него модель **статична относительно костей**, но движется вместе с боевым anchor. Это не полноценная боевая анимация.

**Не сливать без разрешения владельца.**
