# Техническое состояние прототипа — сводка к TDD 1.0

**Снимок 16.11.2026** по структуре игрового `main` и `README.md`. **[РЕАЛИЗОВАНО В main]** — описание наличия модулей, не новая утверждённая архитектурная спецификация. Исторический [TDD 1.0](Pepelny_tron_TDD_1.0.md) описывает стартер 05.11.2026, а не нынешнюю систему. Перед каждым изменением перепроверять реальные файлы.

| Область | Фактическая текущая реализация | Требования для изменений |
|---|---|---|
| Доставка | Статическая игра на GitHub Pages, без сборщика; порядок `<script>` — в `index.html`, номер в `package.json` и футере | Нет новых production-зависимостей и серверного аккаунта без обоснования |
| UI | HTML/CSS, экранная навигация через `game.js`; утверждённый стиль штаба и коллекции; отдельный `lore-campaign-ui.js` | Не ломать touch, 844×390/932×430, safe-area, landscape и возврат |
| Бой | `combat-core.js`, `ability-data.js`, `battle-animation.js`, `enemy-decision.js`, `npc-enemy-data.js`, `npc-story-ops-adapter.js`, `npc-battle-intel.js` | Сохранять детерминируемые правила, инициативу, выбор целей, анимационную синхронизацию |
| История | `lore-campaign-data/core/scenes/pilot/act2/trials/scene-runtime/scene-save`, отдельный лорный ключ | Наращивать граф без изменения старых node ID; первый выбор остаётся в сейве, повтор не переписывает |
| Прогресс | `progress-v3-core.js`, `save-core.js`, локальные сохранения браузера и доменные ядра режимов | Тестировать отказ записи, миграции и отсутствие двойных наград |
| 3D | Babylon.js 9.33.2 через фиксированный CDN; модели `*-glb-runtime.js`, сцена/индикаторы `arena-*.js` | Производительность на мобильном приоритизировать, не размножать Mesh/рендер-циклы |
| Кеш | `model-cache-sw.js`, `model-cache-client.js`, версия ассетов по хешам | Не менять ключи кеша и модели без регрессии |

**Проверки:** `npm test` — проверки синтаксиса и Node-сценарии; GitHub Actions дополнительно запускает браузерные Chromium/WebKit, реальные WebGL-бои и ландшафтные размеры. На PR #353 получено **646/646 Node и 27/27 CI**; после слияния этого PR на `main` проверены успешные Node CI и Pages. Это **не** тест на физическом iPhone.
