# NETWORK-UI-000: макет экранов разведсети

**Статус:** [ПРЕДЛОЖЕНИЕ]. Это визуальный макет к [NETWORK-001](../../NETWORK_001_CORE_LOOP_ARCHITECTURE.md), а не реализованный интерфейс. Игра его не загружает. Названия зацепок, NPC-составы и все числа иллюстративные: это не канон и не баланс.

**Формат:** iPhone в горизонтальной ориентации, 844×390. Стиль по [UI_DESIGN_SYSTEM.md](../../UI_DESIGN_SYSTEM.md): сцена штаба под затемнением, бронза и графит, одна читаемая панель, цели нажатия от 44 px.

## Как открыть

- **Снимки:** папка `screens/`.
- **Живые экраны:** откройте любой `*.dc.html` в браузере из локальной копии репозитория. Маленький `support.js` в этой папке подставляет данные. На экранах 2–4 работают выбор карточек, вариантов и вкладок, между экранами работают ссылки. Картинки берутся из `assets/` игры.
- **Холст с правками:** исходный холст Claude Design «Разведсеть — макет экранов» (`canvas.json` — его раскладка). При изменениях холста обновлять эту папку отдельным PR.

## Что в макете условно

- Рамки поверх доски и стола на картине штаба стоят приблизительно. При реализации их нужно подогнать под реальные координаты хотспотов HQ.
- Поздние материалы показаны заглушкой `[поздний материал]`: их список ещё не утверждён (NETWORK-001, §9, вопрос 6).
- Шрифты: Georgia в заголовках и Inter в тексте, как в текущей игре. Без сети Inter заменяется системным шрифтом.
