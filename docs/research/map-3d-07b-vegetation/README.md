# VEG-01: готовая растительность для Садов
[В РАЗРАБОТКЕ]. Owner requested ready-made grass/shrubs/trees instead of spending AI generation quota. Five CC0 Poly Haven candidates selected from actual source pages, verified provider license https://polyhaven.com/license. Already available 0AD olive/scrub remain low-cost comparison (CC BY-SA 3.0). Local network DNS unavailable; use existing verified intake method from research #600. This workflow downloads original glTF + dependencies, verifies MD5, records SHA256, imports in pinned Blender, renders source and candidate at matched angles, exports actual textured GLBs and reports geometry/size/alpha mode. Simplified candidate is not automatic acceptance: leaf cards and transparency may degrade, dense sources may be rejected. No public to3D binary or changes to game. No runtime vegetation yet. Review actual evidence and then select models, pack shared textures/instances, place in cultivated pockets and shade, not uniform carpet. Species and exact climate are not canon. Owner generation backlog recorded separately.
